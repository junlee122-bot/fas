# IRON DOMINION — 1942

제2차 세계대전을 출발 조건으로 삼는 국가·전선·커리어 대체역사 전략 게임입니다. 실존 지도자를 따라가는 대신 사용자가 국가 조직의 보직에 취임해 승진하고, 군·정·정보 체계를 운영하며, 원래 역사에 없던 세계 질서를 만듭니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 시뮬레이션 엔진 검증은 `npm test`로 실행합니다.

## 현재 플레이 가능한 시스템

- 영국·미국·소련·독일·일본·중국·영국령 인도·자유 프랑스·이탈리아와 한국 임시정부·베트민·인도네시아 독립운동·필리핀 저항군까지 13개 플레이 진영
- 1942년 시점에 맞춘 13개 벡터 국기 체계: 미국 48성기·이탈리아 왕국기·필리핀 전시기와 임시정부기·망명정부기·독립운동기를 현대 국기와 구분해 국가 선택·지휘부·대시보드에 일관 표시
- 국가별 정치 5단계·군사 4단계·정보 4단계의 13개 시작 보직, `★★★★★` 국가 최고위부터 `★☆☆☆☆` 현장직까지 네 번 이어지는 성과 기반 승진
- 169개 시작 보직마다 1942년 실존 인물과 실제 당시 직책을 표시하고, 게임용 재구성 보직·활동 위장·직급별 인사권을 분리해 사용자가 그 인물을 대체하는 취임 구조
- 13개 진영별 최소 200명, Wikidata QID로 신원을 추적하는 2,860명 규모의 실존 인물 디렉터리와 1942년 직책·기관·제약을 별도 검증한 핵심 정치·군사·정보·민간 전문가 계층을 함께 구성
- COI→OSS→SSU→CIG→CIA, BCRA→SDECE→DGSE, NKVD→MGB→KGB, SIM→SIFAR 등 40개 정보기관·레지스탕스·군 정보망의 창설·해체·승계를 연도와 세계선 선택에 따라 구현
- 해당 기관이 활동하는 연도에만 관련 인물이 영입시장에 등장하고, 스카우트로 능력·충성·이중공작 위험·기관 마찰·실제 직책과 출처를 확인하는 FM식 비밀 인재시장
- 직접 가해자로 분류된 인물은 일반 영입 대상에서 제외하고, 게슈타포·RSHA·헌병대·NKVD 등 국가폭력·전쟁범죄 기관은 감시·해체·사법처리 및 정통성 위험을 숨기지 않고 모델링
- 기본 진입 화면을 전황 지도에서 분리한 지휘 본부 대시보드: 결재 업무함, 준비도 산정 근거, 전구 요약, 취약 전선, 조직 상태, 생산·연구 결과 미리보기
- 전쟁 승리 뒤 엔딩으로 종료하지 않고 같은 국경·인물·기술·국고·부채·물가·산업·외교·세계선을 이어받아 `국가 운영 단계`로 계속하는 전쟁→국가 연속 캠페인
- 전황·국내 정통성·재정 여력·산업 전환력·외교 출구를 합산한 전환 준비도와, 완전 승전뿐 아니라 준비도 45·안정도 35 이상에서 선택하는 협상 종전 경로
- 전후 국가 운영에서 국가 성과·국민 위임·고용·복지·교육·주택·제도 역량·민수 산업·불평등·사회 불안을 새 핵심 지표와 승리 조건으로 추적
- 전시와 전후를 같은 인과관계로 잇는 국가 시뮬레이션: 6개 인구집단의 생활수준·승인·급진화가 국가별 권력집단, 6개 핵심 상품의 가격·공급, 5개 법·제도와 행정역량을 거쳐 주간 결과로 이어지는 공통 골격
- 가장 큰 공급 붕괴·행정 과부하·권력투쟁·보건·민생 압력을 `원인 수치 → 예상 결과 → 담당 화면`으로 연결하는 구조적 압력 대시보드와 [국가 시뮬레이션 설계 문서](./GAME_FRAMEWORK.md)
- 조세 부담·공공지출 수준과 재건·복지·교육·산업·외교·안보 6개 부처의 합계 100% 예산, 균형 재건·사회계약·개발국가·개방 공화국·안보 공화국 5개 장기 노선
- 매주 세입·지출·재정수지·부채·물가와 정책별 민생 효과를 동시에 계산하고 `원인 → 결과 → 향후 영향`으로 설명하며, 208주마다 국민 위임으로 정권 연속성을 평가하는 국정 엔진
- 13개 플레이 진영 모두에 서로 다른 민간정부·군부·정보기관·당·왕실·지역·저항조직 권력집단을 두고, 안정도·전황·재정·물가·보급·정당성·참모 충성·집단 간 대립을 매주 합산하는 동적 쿠데타 위험 엔진
- 관찰·위험·임박 4단계와 다음 주 시도 확률, 원인별 수치 기여도, 파벌 지지·불만·조직력·상호관계를 한 화면에서 설명하는 국내 정치위기 상황실
- 사용자의 시작 보직에 따라 정치협상·충성부대 배치·방첩 역공작 권한이 제한되며, 쿠데타가 진압·권력분점·정권교체로 갈리고 실패 뒤에도 새 정부 아래에서 캠페인이 계속되는 권력 승계 구조
- 최고 지휘부·국가 운영·전쟁 수행으로 묶은 확장형 부서 메뉴와 기능명·용도·미처리 업무를 동시에 읽는 화면 탐색 체계

- 선형 라이브러리 아이콘을 대체하는 28종 군사 휘장형 SVG 아이콘과 금·강철·연합·위험·보급 상태별 색상 체계
