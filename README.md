# IRON DOMINION — 1942

제2차 세계대전을 출발 조건으로 삼는 국가·전선·커리어 대체역사 전략 게임입니다. 실존 지도자를 따라가는 대신 사용자가 국가 조직의 보직에 취임해 승진하고, 군·정·정보 체계를 운영하며, 원래 역사에 없던 세계 질서를 만듭니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 시뮬레이션 엔진 검증은 `npm test`로 실행합니다.

## 현재 플레이 가능한 시스템

- 영국·미국·소련·독일·일본·중국·영국령 인도·자유 프랑스·이탈리아 9개 플레이 진영
- 국가별 상급·중급·현장급 보직과 군사·정치·정보 커리어, 성과 기반 승진
- 유럽·지중해와 아시아·태평양 양대 전략 지도, 총 50개 지역
- 국가마다 서로 다른 2개 대체역사 진로와 실제 국가 지표 효과
- 정치·보급·기상·정보를 전환해 보는 4개 작전 지도 레이어와 전구 전환
- 주간 단위 전략 턴 및 자동 전선 이벤트
- 3주 단위로 현재 플레이 진영의 취약 전선을 분석해 반격하는 상대 진영 AI
- 인접 지역 공세 계획과 전투 해결
- 정찰·접근·주력 교전·돌파/추격이 앞 단계의 모멘텀을 이어받는 4단계 작전 전투 엔진
- 신중·균형·총력 공세 태세와 지형·보급·정보망·지휘관·국가 교리가 결합되는 전투 계산
- 단계별 우세도, 전력·조직력·보급 손실과 전과를 기록하고 다시 열람하는 전투 후 보고서
- 지휘관별 참전·승리·승률·피로 누적, 5단계 복무 레벨과 선택형 지휘 특기 4종
- 승전 성과에 따라 종군장·전공장·돌파장이 누적되는 부대 전투명예와 영구 작전 기록
- 지휘관 특기·연구 슬롯·미배정 공장·국가 원칙·대기 부대를 우선순위로 정리하고 관련 화면으로 연결하는 행동 센터
- 고대비 표시·큰 지도 라벨·화면 효과 감소·음향을 독립 저장하는 사용자 환경 설정과 G/N/Space/Esc 단축키
- 기본 가독성 우선 모드, 확대된 핵심 정보와 조작 영역, 즉시 표시되는 사이드 메뉴 설명 툴팁
- `Ctrl+K`로 화면·전구·행동을 한글과 별칭으로 검색하고 방향키·Enter로 실행하는 빠른 이동 팔레트
- 현재 관리 화면의 목적을 설명하는 컨텍스트 바와 가장 중요한 다음 행동 한 건만 제안하는 지휘 보좌관 카드
- 작전·국내·외교 분류, 실시간 전문 검색, 결과 건수와 빈 상태를 제공하는 전쟁 일지
- 캠페인 저장 삭제 전 확인 절차, 이름이 있는 공장 증감 버튼과 비활성화 사유 안내
- 유럽·아프리카·아시아·태평양이 한 테이블에 놓인 3D 지휘실 아트와 가독성 중심의 캠페인 선택 화면
- 장군·사단 로스터, 능력치, 피로도, 보급 및 조직력
- 장군 인사 교체, 사단별 야전 훈련과 지휘 점수 운용
- 작전·군수·병기·인사·정무 5개 부서의 직속 참모진, 능력·잠재력·충성도·업무량·주급 관리
- FM식 인재 조사 슬롯, 불완전한 능력치 평가, 관심 명단, 관심도·계약금 협상과 부서별 영입
- 주간 실무 경험, 집중 육성, 3단계 승급과 전문 능력 성장
- 핵심 편제 지정, 장비별 우선 조달, 전선·균형·예비대 보급 방침
- 군수 공장 배분과 생산 효율
- 실제 비축량으로 누적되는 전차·항공기·보병 장비·수송선 생산
- 전투·정보·보급 능력에 실제 보너스를 적용하는 6개 연구 프로젝트
- 선택 국가에 따라 다시 구성되고 저장·복구되는 외교 관계와 영향력 행동
- 유럽·아시아 전구별 정보 작전, 작전 위험도, 암호 해독
- 전쟁 내각 결정, 국가 지표, 전쟁 일지
- 경제·군사 교리·사회·외교 4개 영역 12개 국가 원칙과 81개 조합
- 4주마다 발생하는 6종 국가 위기와 18개 대응책, 전선·생산·외교·커리어에 남는 연쇄 결과
- 참모·영입 후보·국가 원칙·위기 선택·전투 태세·전투 보고서·지휘관 성장·부대 전투명예·명령 대기열·비축량까지 복구하는 v8 자동 저장
- 전략적 승리·패배 판정과 캠페인 최종 보고서
- 생산·취약 전선 선정·전투 압력·국가별 캠페인 구성을 검증하는 독립 시뮬레이션 엔진과 자동 테스트

## 방향

현재 버전은 고정된 역사 이벤트를 재연하는 대신 인사·정책·생산·보급·외교·전투 시스템의 조합으로 결과가 만들어지는 대체역사 샌드박스입니다. 국가·보직·장비·원칙·위기·전구 데이터가 분리되어 있어 추가 국가, 해전·공중전, 정치 파벌, 사용자 시나리오와 장기 커리어를 독립적으로 확장할 수 있습니다.
