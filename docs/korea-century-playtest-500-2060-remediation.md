# 한국·조선 1942–2060 500회 개선 검증

## 결과

동일한 한국 전용 시드 500개를 개선 전·후에 각각 실행했습니다. 각 경력은 1942년 대한민국 임시정부와 독립운동 보직에서 시작해 2060년까지 6,136주를 진행했습니다. 최종 실행은 총 3,068,000주의 실제 전투·경제·연구·보건·선거·쿠데타·세계사 상태 전이를 계산했고 500회 모두 2060년에 도달했습니다.

## 무엇을 고쳤는가

1. **고정 주차 해방 제거**

   정치·군사·정보 보직과 행동 성향에 따라 미리 정해진 주차에 국가 운영으로 넘어가던 규칙을 제거했습니다. 국제 승인 58, 국내 연락망 52, 광복군 준비 50, 국내정진 계획 50과 종합 준비도 62를 실제 전환 조건으로 사용합니다.

2. **실전 경험을 광복군 역량으로 인정**

   전투 직후 전력·보급 손실만 보던 판정을 고쳐 전투 승리와 장기 편제 숙련을 광복군 준비에 누적합니다. 군사 성향의 준비 완료율은 개선 전 0%에서 개선 후 98.8%로 바뀌었습니다.

3. **실패를 막힘이 아닌 대체역사 결과로 전환**

   최초 전환 목표 뒤 104주 동안 준비를 계속할 수 있고, 그래도 조건을 충족하지 못하면 분할 위험 속 과도정부로 이어집니다. 최종 20.4%의 미완료 전환은 모두 이 안전기한 경로이며, 아무 행동도 하지 않는 `rushed` 성향 83회가 핵심 표본입니다.

4. **해방 방식이 건국 초기조건에 잔존**

   해방 준비도와 분할 위험이 새 정부의 정통성·불안·제도 역량에 반영됩니다. 건국 시 조선 영토의 소유·통제 주체를 실제 한국으로 바꾸고 국내정진 준비를 초기 보급 기반에 연결했습니다.

5. **사용자가 미달 원인을 즉시 발견**

   한국 상황실에 현재 연도, 종합 준비도, 분할 위험, 미달 축 수를 표시합니다. 네 준비축 카드는 해당 외교·정보·군사·지도 화면으로 연결되며, 가장 먼저 보강해야 할 축은 주간 브리핑의 긴급·권장 행동으로도 노출됩니다. 협상 건국을 시도하면 미달 축과 현재 점수를 구체적으로 알려줍니다.

6. **건국 경로를 다섯 갈래로 분화**

   동일한 “연합정부” 문구로 수렴하지 않도록 준비축의 조합과 분할 위험으로 결말을 분류합니다.

## 남은 관찰점

- 준비 미완료 102회 중 국내정진 계획 미달이 101회였습니다. 이를 반영해 국내정진 관련 권장 행동을 주간 브리핑에 추가했으며, 실제 사용자 플레이에서 해당 바로 가기의 발견성과 완료율을 계속 측정해야 합니다.
- 최종 500회에서 쿠데타 경험 세션은 92.4%였습니다. 해방 준비 기간이 늘어난 만큼 정치위기 노출도 증가했습니다. 한국 독립운동 단계에서는 이를 일반 국가의 “쿠데타”가 아니라 임시정부 지도부 위기·정파 분열·조직 장악 시도로 표현하는 후속 콘텐츠 보정이 필요합니다.
- 자동 플레이 500회는 화면을 직접 조작한 사람 500명이 아닙니다. 상태 전이와 선택 결과는 이 테스트로 검증했으며, 클릭 거리·글자 겹침·모바일 배치는 로컬 브라우저 검증을 별도로 수행합니다.
