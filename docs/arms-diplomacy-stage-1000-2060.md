### P2 · 중소국도 외교·면허 경로로 경쟁력을 유지함

### P2 · 잉여장비 의존이 장기 기술고착으로 이어지지 않음

### P2 · 독자·면허·공동개발·수입 경로가 경쟁함

### P2 · 군축·핫라인이 군비경쟁의 오판 위험을 상쇄함

### P2 · 각 결정이 전력·자율성·외교·공급망에 추적 가능한 변화를 만듦
