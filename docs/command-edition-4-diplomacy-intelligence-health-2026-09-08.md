# Command Edition 4 — 외교·정보·보건 작업대

작성: 2026-09-08. 이전 묶음의 [합동군·생산·연구 개편](command-edition-3-forces-industry-research-2026-09-08.md)에 이어, 국가 운영의 세 업무 화면을 개편했다. 콘텐츠 수를 부풀리는 대신 **대상 선택 → 조건과 결과 검토 → 명시적 승인 → 실제 반영 확인**을 일관되게 만드는 묶음이다.

최종 검증: 2026-09-10. 작업 중 실행 환경이 중단되어 재개 후 전체 테스트를 다시 수행했다.

## 구현

### 외교 지휘실

- 국가 관계 / 회담 의제 / 군비·협약 / 이행 기록을 분리했다. 큰 카드 목록 대신 상대국 한 곳과 현안 한 건을 다룬다.
- 데스크톱은 검색 가능한 상대국 목록과 상세 패널, 모바일은 단일 선택 상자를 사용한다. 검색에서 제외된 상대국의 명령을 남겨놓지 않는다.
- 외교 접촉은 기존 정치력 8·관계 최대 +7 규칙을 유지한다. 관계 상승을 동맹 체결이나 영토 획득으로 표현하지 않는다. 실제 접촉 전문을 사건 기록에 남긴다.
- 회담은 개최 시점·상대국 관계·준비도·정치력 조건을 각각 표시하고 캠페인당 한 번만 타결한다.
- 군비 정책과 비축은 즉시 비용·효과 및 장기 검증 시점을 분리한다. 미리보기와 실제 처리는 기존 순수 엔진을 사용한다.
- 정책·회담·비축의 승인 검토와 새 사건 기록은 공통 전후 차이 계산을 사용한다. 예를 들어 전력 97에서 명목 +11 정책은 실제 98.98(+1.98), 비축 89에서 +16은 100(+11), 전쟁 지지도 99에서 회담 +3은 100(+1)이다. 위험 상승의 부정적 의미도 반영하고, 상위 네 지표만 남겨 부작용을 누락하지 않는다. 이 경계값은 자동 테스트로 확인했다.
- 새 정책 이행 요약에서 명목 설계값을 쓰는 곳은 상한·체감 적용 전임을 명시한다. 과거 저장에 전후 자료가 없는 옛 사건 기록은 추정해 덮어쓰지 않았다.
- 검토 후 국가·주차·자원·관계·권한·군비 기록이 바뀌면 재검토를 요구한다. 같은 승인안을 두 번 전송하지 않는다.

### 정보국

- 정보 현황 / 공작 계획 / 진행·보고 / 기관·인물로 분리했다.
- 사용자가 선택한 공작 ID로 검토하고 확정한다. 첫 번째 공작을 암묵적으로 실행하지 않는다.
- 기존 공식 국가공작 규칙은 정치력 7(정보직) 또는 10, 정보망 최대 +4, 선택 공작 진척 100의 **즉시 완료**다. 위험 수치는 참고값이며 이 경로에 확률 판정이나 여러 주의 임무 진행을 새로 만들었다고 표시하지 않는다.
- 개인 이중스파이·외국 포섭 커리어는 기존 별도 비밀 커리어 화면으로 연결한다. 국가공작과 개인 커리어를 같은 실행으로 오인하지 않도록 구분한다.
- 진행·보고는 실제 저장된 진척을 읽는다. 저장되지 않은 과거 완료 주차·손실·비용을 만들어내지 않는다. 새 집행 사건에는 실제 비용·정보망 변화·즉시 완료 규칙을 명시한다.
- 기관·인물은 현재 시대와 관측 가능한 정보 중심으로 표시한다. 숨은 충성도나 이중스파이 정답을 그대로 노출하지 않는다.

### 국가 보건 대비 본부

- 위기 개요 / 대응 정책 / 역량 투자 / 기록·사료로 분리했다.
- 현재 정책과 선택한 정책을 같은 조건의 다음 주 전망으로 비교한다. 사례·사망·재생산지수·병상 부하·공공 신뢰·보건 분야 지출을 보여준다.
- 정책 변경의 즉시 비용은 0이다. 활성 유행이 진행되는 주에 운영비가 발생하며, 유행이 없거나 처음 탐지하는 주에는 운영비가 없다는 기존 규칙을 설명한다.
- 투자는 실제 지출과 상한 적용 후 역량 변화를 표시한다. 요구 지식·중복 구축·자원 부족·진행 중 승인·오래된 검토안도 확인한다.
- 투자 승인 후 다음 미완료 사업으로 자동 이동하던 문제를 고쳤다. 방금 승인한 사업의 구축 완료 상태를 그대로 보여주고 결과 안내로 초점을 옮긴다. 정책도 참모 권고 변경만으로 선택이 바뀌지 않는다.
- 유행 종결 주의 사례·사망을 0으로 잃지 않도록 실제 종결 기록과 누적 사망 차이를 사용한다. 유행이 없으면 미래 병원체나 확정 발생 결과를 예고하지 않는다.

## 실제 로컬 브라우저 검증

주소는 `http://127.0.0.1:4197/`이다. 프시케의 4173은 변경하지 않았다. 영국 최고 정치직 캠페인을 UI로 만들고, 일반 조작과 테스트용 유행 상태를 구분해 점검했다.

| 조작 | 관측 결과 |
|---|---|
| 미국 외교 접촉 검토 | 정치력 120, 관계 78 유지 — 검토는 미집행 |
| 접촉 승인 | 정치력 112, 관계 85, 접촉 전문 1건 |
| 긴급 무기대여·원조선 승인 | 정치력 112→104, 국고 920→990, 정책 기록과 52주 뒤 검증 예약 생성 |
| 두 번째 공작인 지중해 기만 작전 승인 | 정치력 104→94, 정보망 73→77, 진척 34→100. 다른 두 공작은 72/88 유지 |
| 새 정보작전 결과 설명 재확인 | 장거리 정찰의 정치력 86→76, 진척 88→100, 정보망 77→81이 기록됨. 육군 회복 안내 대신 실제 공작 규칙과 보고 화면 안내 |
| 국립 감시 실험실망 투자 승인 | 국고 990→830, 정치력 94→86, 대비 38→43, 탐지 32→48 |
| 투자 승인 후 선택 상태 | laboratory-network 선택 유지, 구축 완료 표시, 중복 승인 비활성, 결과 안내에 포커스 |
| 테스트용 인플루엔자에서 정책 비교 | 감시 유지 1,447사례·14사망, 비상 억제령 941사례·8사망 예상 |
| 비상 억제령 승인 | 정책만 변경, 국고 830·정치력 86 유지 |
| 실제 다음 주 진행 | 941사례·8사망·병상 부하 4.2%·공공 신뢰 65.45로 전망과 일치 |
| 진행 후 참모 권고 변경 | 의료 총동원 권고로 바뀌어도 사용자가 선택한 비상 억제령 유지 |

인플루엔자는 저장 데이터에 주입한 테스트 fixture다. 자연 발생 빈도나 역사 고증을 이 테스트로 검증했다고 주장하지 않는다. 이번 묶음에서 전 국가 수천 회 장기 시뮬레이션을 새로 수행한 것도 아니다.

데스크톱 1440×1000, 모바일 390×844에서 화면을 직접 확인했다. 모바일 세 작업대의 문서 너비는 390px이며 검사한 화면 내부 요소의 우측 넘침은 없었다. 사용한 React 스킬에 따라 파생 전망과 실제 실행을 분리하고, 브라우저 검증 스킬로 실제 조작·저장값·화면을 함께 확인했다.

## 검증·배포 마감

- 전체 테스트: **115개 파일, 1,155개 통과**. `npm test -- --maxWorkers=2`로 최종 변경 전체를 재실행했다. 이전 묶음의 1,017개보다 138개 늘었다.
- 중간 전체 실행은 1,132개를 통과했다. 그 뒤 환경 중단을 걸친 실행에는 5초 제한·worker 응답 시간 초과가 발생했다. 이를 성공으로 취급하지 않고, 환경 재개 후 동시 실행 수 2로 전체 재검증했다. 테스트의 5초 제한 자체는 늘리지 않았다.
- TypeScript 및 `npm run build:pages` 통과. `git diff --check` 통과(줄바꿈 정규화 경고만 있음).
- 최종 Pages 빌드: 메인 JS 3,094.66kB(gzip 973.79kB), 공통 CSS 871.47kB. 큰 청크 경고는 여전히 남는다. 외교·정보국·보건의 별도 청크가 생성되는 것을 확인했다.
- 브라우저 오류 목록은 점검 세션에서 0건. 환경 재개 후 4197의 시작 화면이 다시 로드되고 QA 캠페인이 남아 있지 않음을 확인했다. 테스트는 전용 자동화 브라우저에서 수행했으며 사용자 일반 브라우저의 저장을 가져오지 않았다. 재개 시 세션 백업도 초기화되어 이전 키 값의 완전 복원을 검증했다고 주장하지 않는다.
- 실제 저장 버전은 **38**이며 새 저장 스키마를 요구하지 않는다.
- 커밋·GitHub Pages 배포는 사용자 요청대로 **GPT-5.6 Luna** 작업자에게 위임한다. 대상은 기존 `agent/expand-campaign-depth` 브랜치의 Pages 워크플로이며 `main`을 변경하거나 강제 푸시하지 않는다. 배포 주소: [IRON DOMINION](https://junlee122-bot.github.io/fas/).

## 이번에 하지 않은 것과 후속 과제

1. 외교 작업대 개편은 동적인 쌍방 협상 AI·국경 변경·독립 조약 엔진 추가와 같지 않다. 기존 회담과 군비 정책을 정직하고 읽기 쉬운 실행 흐름으로 정리한 단계다.
2. 국가 정보공작은 여전히 즉시 완료 규칙이다. 후속으로 요원 배속·일정·불확실한 첩보·회수·손실을 실제 주간 상태 기계로 만들어야 한다. 개인 비밀 커리어는 기존 별도 흐름을 보존했다.
3. 헌법·재판·인물 성장·무기 수명주기 같은 깊은 하위 보드는 후속 정리가 남아 있다. 세 업무 화면 개편을 전체 게임의 리디자인 완료로 표현하지 않는다.
4. 메인 번들과 공통 CSS가 큰 구조적 부채는 남아 있다. 이번에는 외교·정보국을 지연 로딩 파일로 분리했다. 지도 삽화 해상도를 낮추지는 않았다.
