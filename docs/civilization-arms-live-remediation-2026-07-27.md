# 문명·무기·외교 실제 게임 이식 감사

작성일: 2026-07-27
검증 범위: 1942–2060, 13개 플레이 국가, 5개 군비 단계, 6개 문명 시대

## 결론

문명 체계의 구조적 콘텐츠 감사와 무기·외교 65,000회 시뮬레이션은 완료되어 있었지만, 시뮬레이션에서 확인한 일부 보완 규칙이 실제 주간 게임 상태·저장·UI에 완전히 연결되지는 않았다. 이번 보완에서 보고서의 여섯 권고를 실제 플레이 규칙으로 이식하고, 문명 선택이 조달 조건을 바꾸도록 두 시스템을 연결했다.

## 기존 산출물 재검증

- 문명 체계: 13개 국가 × 6개 시대 × 10개 영역, 역사 프로그램 60개, 보직별 평가 경로 7,020개.
- 군비·외교: 13개 국가 × 5개 단계 × 단계별 1,000회, 총 65,000세션·1,040,000개 결정.
- 국가별 압축 원자료: 13개 국가 모두 5,000세션을 포함한다.
- 취약 표본 재확인: 필리핀 재건 생존성 88.8%·구식 고착 8.1%, 한국 재건 생존성 93.6%·구식 고착 4.6%.

## 권고별 실제 게임 이식 상태

| 보고서 권고 | 실제 게임 보완 |
|---|---|
| 원조→면허→독자생산 단계 전환 | 앞선 경로의 사용 이력을 저장하고 면허·독자 전환 시 비용 보너스를 부여한다. |
| 소국 공동개발·정비권·기술자·부품 현지화·공동비축 | 저산업 국가 공동개발 할인, 현지화·정비 숙련 누적, 90일 예비부품·탄약 공동비축 행동을 추가했다. |
| 직도입 2회 뒤 현지정비 또는 면허생산 요구 | 같은 경로 직도입 2회 뒤 현지 정비 45 미만이고 면허생산 경험이 없으면 추가 직도입을 잠근다. 카드에 해제 조건을 표시한다. |
| 반복 조달 한계효용·공급자 피로·혼합 규격 비용 | 경로·분야 반복 횟수와 최대 3개 활성 규격을 저장해 다음 견적의 비용, 위험, 공급안보에 반영한다. |
| 전략무기 사전통보·검증·핫라인과 비밀개발 노출 | 규범·긴장완화 정책이 없는 전략무기에 위험을 가산하고 경고한다. 관련 정책을 채택하면 이익으로 전환되며 비공식 조달은 노출을 누적한다. |
| 선택 전 1·3·5년 예상과 사후 원인 추적 | 같은 조달 카드에서 전력·공급·자율·누적비용을 1·3·5년으로 비교하고, 선택 뒤 진행 결과와 조달 원장에 예상→결정→실제 누적을 기록한다. |

## 문명 체계와의 상호 연결

- 에너지·노동 체계는 실효 산업 역량을 높인다.
- 교육·과학 체계는 독자개발 성공률과 기술 흡수를 높인다.
- 교통·정보 체계는 정비·공급 위험을 낮춘다.
- 이 효과는 단순 설명 문구가 아니라 조달 배수, 성공률, 유지비, 공급안보 전망에 반영된다.

## 저장·주간 흐름

- `ArmsPortfolioState`가 전력, 자율성, 상호운용성, 공급안보, 긴장, 확산, 규범 신뢰, 비상비축, 비공식 노출, 분야별 현지화·정비, 경로·분야 사용 이력과 결과 원장을 저장한다.
- 저장 형식은 버전 28로 올렸고 이전 저장은 국가별 역사 기반 초기값으로 자동 보정한다.
- 군비·외교 정책의 검증 연도는 실제 예정 주차로 저장된다.
- 예정 주차에 공급·자율·상호운용·규범·긴장·노출을 합산한 집행 점수를 계산하고 예상 상회·계획 범위·예상 미달 결과를 진행 결과에 남긴다.

## 남은 범위의 성격

65,000회 시뮬레이션은 결정론적 균형·경로 다양성·붕괴 위험을 검증하는 계층이다. 실제 플레이에서는 사용자의 세부 장비 설계, 문명 정책, 외교 관계, 전쟁 결과가 추가로 결합되므로 모든 가능세계의 서사를 사전에 열거하지 않는다. 대신 동일한 저장 상태와 인과 규칙이 선택 조합에 따라 새로운 결과를 만들도록 구성했다.
