# 스팀 리뷰 후속 묶음 — 현장 연동 1차

작업일: 2026-09-08. 기준: `steam-review-2026-09-08.md`, 앞선 `steam-review-remediation-2026-09-08.md`, 사용자 요청인 액티브한 게임 방향 설계와 유사 장르 전반의 비교 조사.

## 이번에 실제로 바뀐 것

### 1. 본부에서 현장을 선택하고 지시하기

`LivingWorldScene.tsx`를 본부의 역할별 책임 안내 아래에 연결했다. 전체 분석을 펼치지 않아도 생산 지구·생활 시장·보건 거점·참모 회의실을 선택할 수 있다. 선택한 장소의 상세 정보만 보여주며 현장 전체도 접을 수 있다. 민간 커리어에는 국가 지휘용 현장을 강제로 노출하지 않는다.

생산 지구에서는 실제 생산 라인을 선택하고 공장 역량 1개를 군수↔민수로 전환한다. 결재 전에 소비재 공급과 전시 기본 생산력을 비교한다. 결재는 기존 `production`을 변경한다. 배경을 누르거나 화면을 접었다 펴는 행동은 자원·시간·성과를 바꾸지 않는다.

현재 산업 자료는 국가 합계이고 생산라인에 지역 ID가 없다. 따라서 화면은 **국가 현황 모식도**라고 표시한다. 공장 그림을 특정 도시의 실제 공장·고용 인구로 속이지 않는다. 보건·시장·참모 장소는 실제 상태를 읽고 해당 기존 업무 화면으로 연결한다. 모든 장소에 새로운 독립 미니게임이 생긴 것은 아니다.

산업 직접권한은 화면과 명령 처리 양쪽에서 검사한다. 다른 보직은 상신 또는 보고 확인으로 연결한다. 승인 메시지는 버튼 자체가 가정하지 않고 저장된 실제 명령 이벤트에서 가져온다. 이후 주간 결산이 존재할 때만 후속 검증 안내를 표시한다.

### 2. 군수 배치 → 소비재 공급 → 실제 사회 반응

`nationalSimulation.ts`의 소비재 공급에 실제 군수 배치 비율을 추가했다. 총 공장 30개인 단위 시험에서 군수 0/15/30개 배치 시 소비재 공급은 60.6/48.6/36.6이다. 군수 역량 1개를 민수로 돌리면 이 조건에서 공급이 0.8 오른다. 군수 라인끼리만 재배치하면 민수 여력은 변하지 않는다.

`nationalEconomyFeedback.ts`가 식량·소비재·연료·철강·수송의 부족을 물가·신뢰·안정·사회 불안·고용의 추가 변화로 계산한다. App의 실제 주간 진행에서 전시와 국정 모두 기본 결산 뒤 한 번 적용한다.

- 주간 최대 변화: 물가 0.08%p, 신뢰 0.12, 안정 0.06, 사회 불안 0.12, 고용 0.08. 실제 변화는 부족 강도에 비례하므로 작은 부족이 최대 벌점으로 뛰지 않는다.
- 지표는 제한된 목표 구간에 수렴한다. 같은 부족을 118년 동안 반복했다고 무한 벌점이 쌓이는 고정 감점 방식이 아니다.
- 정상 공급·정상 지표는 중립이다. 충분한 공급 회복은 비정상 지표만 완만히 정상 구간으로 이동시킨다.
- 세금·세입·차입·국고는 이 함수에 없다. 보건 손실도 중복 계산하지 않는다.
- 결산은 전체 국가 변화와 **공급 경로만의 추가 기여**를 구분한다. 다른 주간 엔진과 합산 후 0~100 경계가 적용된다.

`미배정 공장을 0개로 만들라`는 긴급 권고는 제거했다. 남은 역량은 민수 여력이라는 정보이며, 군수 확대의 이익과 생활재 공급의 기회비용을 비교하게 한다.

### 3. 참모 이야기에 플레이 기록 연결

`staffNarrative.ts`가 선택적 실제 사건 근거를 받는다. 원인에는 기록 ID·발생 주·설명·출처가 저장되고 같은 근거를 반복 소비하지 않는다. 최근 8주 이내의 현재 관리 가능한 인물만 연결한다. 단독으로 확인된 인물에게 가상의 동료를 추가하지 않는다.

실제 앱 연결(`staffPlayEvidence.ts`)은 다음으로 제한했다.

- 전투 보고서의 지휘관 이름과 현재 참모가 유일하게 일치하는 완료 전투. 진행 중인 교전을 최종 승리라고 부르지 않는다.
- 실제 `joinedWeek`가 있는 신규 합류. 초기 배치된 명단은 사용자가 영입한 성과로 만들지 않는다.

현재 신뢰할 만한 인물 연결 자료가 없는 임무 손실은 임의 담당자에게 떠넘기지 않는다. API는 임무 실패·약속 위반 같은 추가 증거도 받을 수 있지만, 그것을 앱의 모든 사건과 이미 연결했다고 주장하지 않는다.

자동 내부 점검에서는 기록 없는 승리·유출·사임 발언을 실제 사건처럼 단정하는 문구를 제거했다. UI가 `플레이 기록 연결`과 `자동 내부사정`을 구분한다. 인물의 게임 내 판단은 실제 인물의 역사적 발언이라는 뜻이 아니다.

### 4. 함께 고친 일관성 문제

- 해외 이적 시 과거 국가의 승인·결산이 현재 국가 현장에 섞이지 않도록 새 이벤트에 국가 범위를 저장하고, 최근 국제 경력 이동 이전의 기록을 제외한다. 국가 범위 없는 구기록은 임의로 추정하지 않는다.
- 두 명이 관련된 참모 현안에서 첫째/둘째 중 누구라도 실제 관리 범위에 있으면 현장 개수에 포함한다. 실제 대응 권한과 같은 조건이다.
- 국정에서는 실제로 계산하지 않는 군수 납품을 `/주 생산량`처럼 약속하지 않는다. 현재는 배치 보존과 민수 공급 기회비용만 반영함을 명시했다.
- 모바일 실제 클릭에서 정보 알림이 다음 주 버튼을 덮는 것을 발견했다. 상단 대신 하단 배치, 입력 통과, 화면 폭 제한, 12px 글자와 줄바꿈으로 수정했다.
- 접힌 현장은 키보드·보조기술에서도 숨겨진다. 장소 상태는 색뿐 아니라 텍스트로 표시하고 움직임 줄이기를 지원한다.

## 유사 게임 전반을 반영한 상향 설계

[별도 조사·설계 문서](active-world-design-research-2026-09-08.md)에 공식 출처와 버전 한계, 필요한 데이터, 우리 게임에 맞춘 변환, 검증 기준을 정리했다. 문명·삼국지·Victoria 3에 FM·CK3·HOI4·RimWorld·Frostpunk 2·XCOM 2·Total War·Stellaris를 더해 11개 사례를 검토했다.

확장 방향은 여섯 새 메뉴가 아니라 여섯 연결이다: 업무와 배속, 사람과 기억, 생산과 영토, 보급과 전쟁, 원인이 이어지는 현안, 시대 전환 이후에도 남는 책임.

공통 루프는 **현장 발견 → 관련 인물·근거 → 권한 내 명령 또는 상신 → 실제 주간 결산 → 현장 변화·기억·후속 현안**이다. 참고 게임의 코드·자산·대사·상표 디자인을 복제하지 않는다.

## 아직 남은 작업과 다음 순서

1. **전후 군수의 완결성:** 국정 단계 군수 생산·납품·유지비·정비의 일관된 결산. 현재 한계는 UI에 숨기지 않았지만 엔진 기능 자체가 해결된 것은 아니다. 가장 가까운 후속 개선 대상으로 둔다.
2. **작전 현장:** 실제 배속·지원·보급·다주간 진척을 지도 위 선택과 하나로 연결. 이번 새 현장은 산업 중심이며 별도 전투 현장 완성본은 아니다.
3. **참모 회의장:** 실제 인물·현안·기억·권한을 유지한 채 대화와 책임을 한 장소에서 처리. 기존 참모 현안 화면으로 연결하는 수준을 넘어서는 후속 작업이다.
4. **지역 생산·수송:** 지역 귀속과 합계 보존, 실제 항만/철도 경로, 공급 수요·도착 모델을 먼저 만들고 그 뒤 지도 시설과 차량을 그린다.
5. **사건의 리듬:** 새 팝업 수를 늘리기보다 동일 원인의 경고·악화·개입·회복을 추적하고 안정기에 준비할 여백을 제공한다.

이번 묶음은 3D 전술 게임, 실시간 주민 AI, 지역별 인구·고용, 의회 전체 시뮬레이션까지 완성한 작업이 아니다. 기존 국가 집계형 경제도 그대로 존재한다. 대규모 App 결합과 빌드 청크 문제 역시 남았다.
