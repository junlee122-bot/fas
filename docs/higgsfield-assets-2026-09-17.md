# Higgsfield 지휘 데스크 삽화 생성·적용

## 완료 범위

기존 Starter 요금제에서 **GPT Image 2.5 / high / 2k / flare / 3:2**로
군사·정치·정보 업무실 삽화 3장을 생성했다. 세 작업 모두 completed를 확인했다.
계정 잔액은 253에서 244로 감소해 총 9크레딧 사용을 확인했다.
요금제 업그레이드·크레딧 구매·중복 생성·다른 제공자 사용은 하지 않았다.
이 조합의 실제 사용 가능성을 확인한 것이며, 모든 모델의 품질 비교 결과는 아니다.

- 원본: `design/source-assets/command-desk/*-workroom.png`, 모두 2048×1360.
- 게임용: `src/assets/command-desk/*-workroom.webp`, 같은 해상도의 무손실 변환.
- 세 파일 모두 원본과 변환본을 RGBA 픽셀로 디코딩하여 동일함을 확인했다.
- 작업 ID·시각·모델·프롬프트·크기·SHA-256은 `design/command-desk-generation.json`에 기록했다.
- `src/commandDeskArt.ts`의 세 import만 새 삽화로 연결했다. 공유 업적 삽화는 보존했다.
- 절제된 회화풍, 청회색·올리브·아이보리 색조와 세 장의 시점·빛을 일관되게 유지했다.
- 실존 인물의 초상이나 특정 국가의 고증된 사무실이 아닌 익명 인물의 분위기 삽화다.
  1936–1959 표시 제한과 ‘실제 사건 기록 아님’ 설명을 유지한다.
- 원래 UI·권한·결재·저장·지도·게임 엔진은 변경하지 않았다.

## 검증 결과

1. `commandDeskArt`, `CommandDesk`, `commandDeskAccess` 3개 파일 **88/88 통과**.
2. `npm run build` 성공: TypeScript와 Vite 통과, 신규 세 이미지 모두 빌드에 포함.
   기존 대형 JavaScript 청크 분할 권고는 남는다(주 청크 약 3,502.80 kB,
   gzip 약 1,100.26 kB). 전체 게임 suite를 재실행한 결과는 아니다.
3. 군사·정치·정보 원본을 모두 육안 검토했다. 뚜렷한 손/선 결함이나 읽을 수 있는
   국가 표식·지리 정보·현대 화면은 관찰되지 않았다. 정보 업무실 쪽지에는 읽을 수
   없는 희미한 자국이 있어, ‘완전히 빈 종이’ 프롬프트를 엄밀히 전부 준수한 것은 아니다.
4. 자동 브라우저 CLI 연결은 시간 초과되었다. 이후 Codex 내장 브라우저로 실제
   로컬 화면을 확인했다. 꺼져 있던 서버는 `127.0.0.1:4197`로 재시작했다.
   프시케의 4173은 변경하지 않았다.
5. 기존 영국 군사 캠페인의 지휘 데스크에서 새 military WebP가
   `naturalWidth=2048`, `naturalHeight=1360`으로 로드됨을 확인했다.
   주간 진행·명령·새 캠페인 생성은 하지 않았다.
6. 1920×1080 및 2560×1440 화면을 육안 확인: 삽화와 본문/버튼이 겹치지 않으며
   가로 페이지 넘침 0. 삽화 표시 크기는 약 230×153.3 CSS px.
7. 3840×2160 DOM 계측: 가로 넘침 0, 지휘 데스크 최대 폭 1760 CSS px,
   제목/버튼 내부 가로 잘림 0, 삽화 로딩 정상. 4K 캡처는 전체 화면을 충분히
   판독하지 못했으므로 이 항목은 DOM 계측 결과로 한정한다.
8. 1280×720의 좁은 업무공간에서는 기존 규칙대로 보조 삽화를 숨기며 가로 넘침 0.
   임시 viewport 설정은 복원하고 검증용 탭을 닫았다.
9. 확인한 캠페인 페이지의 오류 로그와 Vite 오류 overlay 없음.
   정치·정보 별도 캠페인 플레이 검증은 하지 않았으며, 두 역할 연결은 회귀 검사와
   빌드 및 원본 검토로 확인했다.

포함하지 않았다. 생성은 라이선스 권리 정리를 확인했다는 뜻이 아니다.
