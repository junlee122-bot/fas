# 장기 전략 서사 시스템 조사·설계 기록

작성일: 2026-08-01

## 목표

아이언 도미니언의 사건을 ‘한 주에 뜨고 한 번 클릭하면 끝나는 선택지’에서 벗어나게 한다. 전쟁·건국·냉전·산업·보건·정보·기후·자동화의 큰 변화가 여러 막에 걸쳐 압력을 만들고, 사용자가 임명한 참모와 국가의 실제 역량에 따라 전개되도록 한다. 역사 이름만 바꾼 고정 이벤트가 아니라 현재 세계선의 강대국, 연합 지지, 연구력, 물가, 보건 위기가 같은 구조를 다른 내용으로 만들어야 한다.

## 공식 자료에서 채택한 원리

### Football Manager — 서로 다른 기대와 피드백

- Football Manager의 Supporter Confidence는 이사회가 보는 재정·전략 목표와 지지자가 보는 정체성·라이벌·개인 성과를 구분한다.
- 게임 적용: 국면의 성패를 단일 국가 점수가 아니라 정당성, 권력연합, 공약 신뢰, 국가 역량과 책임 참모의 관점으로 나눴다.
- Football Manager 26의 재설계 UI는 자주 쓰는 영역을 직접 연결하는 북마크를 제공한다.
- 게임 적용: 지도와 분리된 하나의 상황실 안에 막 순서, 진척, 압력, 담당자, 예상 결과, 연대기를 함께 배치했다.

자료:

- https://www.footballmanager.com/features/supporter-confidence
- https://www.footballmanager.com/fm26/features/fm26s-reimagined-user-interface

### Civilization VII — 성장, 위기, 유산, 재출발

- Civilization VII 개발 설명은 후반부 스노우볼링으로 선택의 의미가 약해지는 문제를 명시하고, 시대별 유산 경로와 단계적으로 심화되는 위기로 대응한다.
- 위기는 한 번에 끝나지 않고 단계가 진행될수록 강도가 커지며, 하나의 정답 대신 적응 방식을 요구한다.
- 게임 적용: 모든 장기 국면을 4막으로 나누고, 막마다 집중 지휘·연합 협상·제도 실험을 다시 선택하게 했다. 실패는 게임오버가 아니라 제도적 상처가 되어 최종 유산을 바꾼다.

자료:

- https://civilization.2k.com/it-IT/civ-vii/game-guide/gameplay/ages-explanation/
- https://civilization.2k.com/en-GB/civ-vi/

### Stellaris — 진행되는 상황과 플레이어가 만드는 위기

- Stellaris: The Machine Age는 새로운 상황(situations)과 플레이어가 직접 위기 경로를 밟는 구성을 강조한다.
- 게임 적용: 국면은 배경 설명이 아니라 매주 진척과 압력이 동시에 움직이는 상태이며, 플레이어가 자원 투입과 대응 원칙으로 위기를 가속하거나 안정시킨다.

자료:

- https://www.paradoxinteractive.com/games/stellaris/add-ons/stellaris-machine-age

## 구현한 구조

### 10개 시대 국면·40개 막·120개 대응 조합

1. 생존의 동맥과 연합 군수망
2. 해방 전선과 건국의 정당성
3. 원자력의 문과 최후무기의 딜레마
4. 분할된 세계와 동맹의 장기 대치
5. 독립의 물결과 신생국 협상장
6. 에너지 충격과 화폐 질서의 재편
7. 위성·방송·네트워크가 만든 정보 질서
8. 국경을 넘는 감염과 공중보건 계약
9. 기후 충격과 산업 문명의 전환
10. 알고리즘 국가와 인간의 최종 결정권

각 국면은 4막이다. 각 막에서 사용자는 다음 세 원칙 중 하나를 선택한다.

- 집중 지휘: 빠른 통제와 초기 진척, 높은 정치비용과 압력 상승
- 연합 협상: 낮은 압력과 정당성, 연합 지지가 낮으면 진행 지연
- 제도 실험: 교육·연구·참모 역량에 비례한 높은 잠재력, 실패 시 자원 손실

따라서 정의된 선택 조합만 `10 × 3^4 = 810`개이며, 담당 참모, 막별 예비자원 투입, 후퇴 시점, 상처, 국가별 초기 능력과 시대 조건을 곱하면 같은 국면 안에서도 수천 개의 실제 결과 궤적이 생긴다.

## 인과관계 계산

매주 다음 값을 화면에 그대로 보여준다.

- 진척: 분야별 국가 역량 + 담당 참모 능력·충성·부서 적합도 + 대응 방식 + 기세 - 현재 압력
- 압력: 적 압력 + 보건 위기 + 선택 방식의 압력 보정 + 장기 시한 초과
- 기세: 높은 역량이면 조금씩 누적되고 낮은 역량이면 하락
- 후퇴: 압력 100에 먼저 도달하면 진행 일부를 보존하고, 대응을 다시 선택하며, 해당 분야의 제도적 상처가 남음
- 결말: 기세 + 책임자 능력 - 후퇴 횟수 - 잔여 압력으로 전환적 합의·경합 속 타협·상처 입은 돌파를 판정

## UX 원칙

- 지도를 열지 않아도 전략 서사 카드만으로 ‘현재 질문, 다음 선택, 진행 속도, 위험, 담당자’를 파악할 수 있다.
- 선택 버튼에 정치력·국고 비용, 예상 주간 진척, 예상 주간 압력, 예상 남은 주를 결정 전에 표시한다.
- 새 막이나 후퇴가 발생하면 장기 자동 진행을 취소하고 사용자에게 결재를 돌려준다.
- 전환점은 인과관계 연대기에 저장하고 완결 뒤에도 책임자, 소요 기간, 상처, 유산을 조회할 수 있다.
- 옛 저장에는 기본 상태를 보충하고, 존재하지 않는 국면 ID는 제거한다.

## 고정 재현이 아닌 대체역사

역사 자료는 ‘원자력은 반드시 일본에 사용된다’, ‘냉전은 반드시 미국과 소련이다’ 같은 고정 전개로 쓰지 않았다. 대신 다음 구조를 데이터화했다.

- 원조와 주권의 교환
- 해방 연합과 과도 권력의 대표성 충돌
- 비밀 과학과 민간 감독
- 동맹 방어선과 대리전의 확전 위험
- 독립 뒤 부채·기업·기지·국경 승계
- 물가·환율·에너지 충격의 고통 배분
- 언론 자유와 정보전·감시 권한
- 검역·생계·백신 배분의 사회계약
- 산업 전환의 지역·세대 비용
- 자동화 효율과 인간 최종결정권

실제 플레이에서는 현재 살아남은 국가, 사용자의 보직, 참모진, 연합 지지, 물가, 연구와 보건 조건이 그 구조의 주체와 결과를 결정한다.
