# 국가 비축 → 부대 장비 지급

## 구현 범위

기존 국가 가용 비축을 특정 부대에 지급하고 실제 차감·수령 기록을 남기는 플레이를 추가했다. `합동군/국방·동원 → 편제·합동작전 → 육군 → 부대 현황`에서 지급안을 검토한다. 지휘부의 지휘실·창고와 조직/산업의 이행 목표에서도 지급 창구로 연결한다. 권한이 없는 보직은 기존 보고·상신 경로를 유지한다.

지급은 두 단계다. **검토는 자원을 바꾸지 않으며, 최종 승인에서만 국가 비축과 부대 기초 보급을 함께 변경한다.** 현재 국가·부대·주둔지·주차·재고·보급이 검토 후 달라지면 새 비용을 자동 집행하지 않고 다시 검토하게 한다.

## 게임 규칙과 의도적인 한계

- 직접 지휘권이 있는 예하 부대, 자국 소유·아군 통제 육상 거점, 거점 보급 50 이상에서만 현지 지급한다.
- 준비·재편 상태만 가능하며 이동·교전·진행 중 명령·해상 수송 중에는 지급하지 않는다. 주간/자동 진행 중에도 승인하지 않는다.
- 부대별 주 1회, 기초 보급 최대 +10(상한 100). 보병·공수·해병은 기초 보급 1당 보병 장비 10 게임 단위, 기갑은 전차 2 게임 단위가 필요하다. 상한 근처에서는 실제 증가량에 해당하는 비용을 올림해 계산한다.
- 이 환산은 게임 설계다. 역사적 편제별 실물 장비 수량이나 실제 부품 명세를 뜻하지 않는다.
- 지급은 국가 비축의 현지 인도를 추상화한다. 새로운 원격 배송 경로·시간·차량 이동을 재현한 것은 아니다. 동맹국의 통행권만으로 지급할 수 없다.
- 국가 도착 전에 남아 있는 지역 창고·예약·수송 중 물량을 사용할 수 없다. 국가 가용 비축에는 기존 비축과 신규 도착이 섞이므로 특정 생산 묶음의 출처로 단정하지 않는다.
- 부대 모델별 보유량 전체를 새로 시뮬레이션하지 않는다. 정확한 차감량과 수령 부대·거점·주차·기초 보급 전후를 기록한다.
- 납품 약속 실적을 재가산하지 않는다. 제식 장비 패키지 선택, 자동 주간 보급, 전투 보정은 별도 체계다. 기존 부대 화면의 보급 지표는 `전투 보급(보정)`으로 표시했다.

## 저장과 안전성

저장 버전 46에 국가별 지급 원장을 추가했다. 기존 저장에 필드가 없으면 빈 원장으로 시작하며, 명시적 잘못된 데이터는 빈 원장으로 바꾸지 않고 격리한다. 다른 국가의 기록과 미래 기록을 현재 실적으로 표시하지 않는다.

최근 영수증은 국가별 120건으로 제한하지만 부대별 최종 지급 주차는 보존해 압축 후 재지급을 막는다. 새 캠페인에서는 초기화하고 국가 전환에서는 국가별 원장을 보존한다. 저장 복원은 기록을 복원할 뿐 지급 효과를 다시 적용하지 않는다.

App에서 최종 보직·소속 권한을 재확인하며, 동기적 처리 잠금으로 같은 렌더에서 연속 승인해 비축 차감을 덮는 경우도 차단한다. 화면에서 대상이 사라지면 다른 부대로 대신 지급하지 않는다.

React 지침에 따라 현재 예상은 실제 상태에서 계산하고, 검토안만 명시적인 사용자 입력 상태로 보존한다. 지급 후에는 같은 주의 추가 지급 예상을 숨기고 실제 영수증을 보여준다.

## 검증 결과

- 관련 새/수정 테스트와 기존 생산·물류·저장·해상 수송 회귀: **29개 파일, 876개 테스트 통과**.
- 타입 검사 및 `npm run build:pages` 통과. 기존 대형 번들 경고는 남아 있다.
- Pages 지리 게이트: 3개 회귀 통과, 육상 385경로/112,367표본 감사 실패 0.
- 원장 엔진 독립 테스트 56개, 패널 독립 테스트 22개가 위 통합 검증에 포함된다.
- 메모리 전용 격리 화면 `/scripts/verify-unit-equipment.html`에서 실제 지급 엔진을 브라우저로 조작했다. 사용자 저장은 읽거나 쓰지 않았다.
- 검토 시 비축 300 유지 → 외부 조건으로 290 변경 시 기존 승인 잠금 → 재검토 후 승인 시 190, 기초 보급 65→75, 실제 지급 1회 확인.
- 같은 주 재지급 잠금, 다음 주 재검토, 검토 후 직접 권한 해제 시 승인 잠금, 다른 기갑 부대 선택 시 이전 검토안 폐기와 전차 20단위 예상 확인.
- 1080p 스크린샷과 1080p·1440p·4K DOM 경계 검사에서 새 패널의 가로 넘침 0. 브라우저 콘솔 경고·오류 없음. 1440p·4K는 수치 기반 레이아웃 검사이며 전체 화면 시각 검증으로 대체하지 않는다.

## 이번 릴리스에 함께 포함할 앞선 묶음

지휘부 기관 운영, 실제 참모 결산, 지역 물류 현장, 해상 수송 현장, 생산·수송·납품 목표 추적을 함께 포함한다. 관련 소스·테스트·검증 화면·9월 24일 설명 문서만 선별한다. 무관한 과거 이미지·대규모 플레이테스트 원자료·원본 미술 폴더는 커밋하지 않는다.

푸시 대상은 기존 `agent/expand-campaign-depth`이며 해당 브랜치의 기존 Actions가 GitHub Pages를 배포한다. 정확한 커밋 SHA, Actions 결과와 배포 반영 여부는 작업 완료 메시지에서 확인한다.

다음 확장에는 생산 묶음 귀속과 부대 모델별 장비 보유/손실/회수, 원격 부대까지의 보급 경로가 필요하다. 이번 현지 지급을 그 전체 공급망이 완성된 것으로 표현하지 않는다.
