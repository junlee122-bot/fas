# 참모의 실제 주간 업무 결산 — 2026-09-24

## 이번 묶음의 결과

지휘 데스크의 참모 업무표와 인물 상세 화면에 **최근 확정 주간 결산**을 연결했다. 다음 주 예측을 과거 실적으로 표시하지 않고, 이미 실행된 주간 엔진의 전후 상태만 기록한다.

사용 흐름은 `주간 진행 → 참모 업무표에서 결과 확인 → 인물 선택 → 변화 내역 펼치기 → 필요하면 전체 주간 브리핑`이다.

### 화면

- 업무표의 기존 5개 열을 유지하고, 부담 전망 아래에 최근 결산 주차와 실제 부담 증감을 표시한다.
- 인물 카드에서 업무 부담·성장도·사기의 전후 값과 증감을 먼저 보여준다.
- 상세 설명은 펼침 영역에 둔다. 충성도·역할 만족·계약 잔여 기간을 포함한 6개 지표를 확인할 수 있다.
- `업무·계약·기본관계 정산`과 `조직 사건 반영`을 분리한다. 두 변화는 합계의 구성요소이지 추가 보상이 아니다.
- 당시 부서·업무 방침·위임·집중 육성 설정을 보존한다. 현재 설정이 달라졌으면 과거 결과라는 안내를 표시한다.
- 계약 만료와 위임 해제, 오래된 기록, 기록 없는 구버전 저장, 유효하지 않은 기록을 별도로 설명한다.
- 주급은 당시 **기준액**으로만 표시하며, 현재 표시 통화 기준임을 밝힌다. 개별 지급 완료나 추가 차감을 주장하지 않는다.
- 좁은 PC 인스펙터를 위해 보조 설명을 12px 이상으로 조정하고 긴 한국어 설명을 줄바꿈한다. 장식용 영문 구분 표시는 11px이다.

### 엔진과 저장

- 전시·국정 양쪽 주간 진행에서 기존 명부 → 업무 정산 명부 → 조직 사건 정산 명부를 캡처한다.
- 업무·조직 사건 엔진을 다시 실행하지 않는다. 새 생산 보너스·보상·비용을 추가하지 않는다.
- `StaffMember.lastWorkReport` 선택 필드를 추가했다. 기존 저장의 `staff` 직렬화에 포함되며, 이전 저장은 기록 없이 정상 시작한다.
- 개인별 최신 기록 1개만 유지해 주간 진행에 따라 저장 크기가 계속 늘지 않게 했다.
- 국가, 보직 ID, 인물 ID, 입사 주차, 결산 주차와 자료 범위를 검증한다.
- 신규 영입은 전임자 기록을 제거한다. 동일 인물의 보직 이동·면담은 과거 기록을 다시 쓰지 않는다.
- 중복 인물, 다른 국가·미래 주차·재고용 이전 기록, 잘못된 통계는 확정 결과로 표시하지 않는다.
- 독립 검토에서 발견한 원본 사기·만족도·계약 범위 검사를 추가했다. 잘못된 값이 getter의 보정으로 정상 기록처럼 바뀌지 않게 했다. 누락된 구버전 선택 필드의 기존 엔진 기본값은 유지한다.

### 로컬 브라우저

`http://127.0.0.1:4197/scripts/verify-staff-work-reports.html`

실제 인사·조직 사건 엔진과 프로덕션 결산 카드를 사용하는 격리 화면에서 다음을 확인했다. 사용자 게임 저장은 읽거나 변경하지 않는다.

1. 첫 결산 전에는 과거 실적을 만들어내지 않는다.
2. 실제 1주 진행 뒤 앨런 브룩의 부담 `31 → 32.5`, 성장 `24 → 30`, 사기 `81 → 83`을 기록한다.
3. 방침을 집중 업무로 바꿔도 이전 결산 숫자는 유지되고 설정 변경 안내가 나타난다.
4. 실제 엔진을 6회 연속 실행하면 제8주 결과가 표시된다. 한 번에 6주를 건너뛰어 기록하지 않는다.
5. 메모리 JSON 저장 후 진행·복원하면 제2주의 원래 기록으로 돌아온다.
6. 브리핑 연결 콜백과 다른 인물 선택을 확인했다. 앨런 튜링의 기록은 브룩의 기록과 혼동되지 않는다.
7. 1920×1080, 2560×1440, 3840×2160에서 380px/480px 카드와 상세 설명을 검사했다. 검사한 카드 내 가로 넘침은 없었다. 임시 브라우저 해상도 설정은 복원했다.

이 검증은 **개인 결산 화면·관련 엔진의 격리 검증**이다. 전체 캠페인의 모든 팝업·저장·권한 흐름을 브라우저에서 끝까지 재현한 것으로 주장하지 않는다. 권한과 영입 흐름은 관련 회귀 테스트로 함께 확인했다.

## 범위와 후속 방향

기록은 참모 개인의 상태 변화이지 국가 전체 생산·연구·전투 실적의 개인 공적 배분이 아니다. 개별 생산 공적은 기존 납품 약속·실제 납품 증빙과 연결해 검증해야 한다.

후속 후보는 결산의 문제 신호에서 면담·부담 경감·재배치로 이어지는 후속 행동을 더 짧게 연결하는 것이다. 이번에는 기존 권한·결재·면담 흐름을 보존했다.

작업은 로컬에 반영했다. 이번 요청으로 커밋·푸시·배포를 실행하지는 않았다. 앞선 물류·해상 수송 묶음과 기존 사용자 파일은 유지했다.
