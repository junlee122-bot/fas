# Higgsfield 삽화와 PC 가시성 개선 — 2026-09-23

## 판단과 적용 범위

새 디자인으로 교체하지 않고 기존 PC 지휘 화면을 보완했다. 평가 기준은 **첫 행동을 찾는 속도, 정보 밀도 유지, 그림의 식별성, 게임 상태와 시각 자료의 분리**다. 아래 평가는 설계 판단이며 사용자 A/B 테스트 결과는 아니다.

| 제안 | 평가 | 반영 |
| --- | --- | --- |
| 기존 삽화의 클릭 확대 | 작은 그림의 내용을 읽을 수 있고 기본 화면 밀도를 유지함 | 기존 24종 공통 삽화와 지휘 데스크에 읽기 전용 확대 창 |
| 통행권·기지권 전용 장면 | 서로 다른 권리의 목적을 구분하는 데 도움 | 국경 연락·항구 정비 2종 신규 제작 |
| 선택 인물만 초상 확대 | 이름·얼굴을 연결하기 쉬우며 목록 행 수는 유지 | 상세 초상 88–112px, 일반 명단 38px 유지 |
| 좁은 PC 작업공간에서도 지휘 삽화 유지 | 기존 1080px 컨테이너에서 사라지던 그림을 접근 가능하게 함 | 130–170px 그림 열, 더 좁은 공간은 단일 열 |
| 경고·업무 상태와 캡션 대비 강화 | 본문과 구분되면서 색에만 의존하지 않음 | 테두리·명시적 상태 문구, 캡션 최소 12px |

| 전면 배경 그림·자동 영상 | 결재 내용과 클릭 영역을 가리고 성능 비용을 높임 | 제외 |
| 모든 명단 초상 확대·추가 장식 아이콘 | 화면당 인원과 정보가 줄어듦 | 제외 |

## 신규 제작물

- 제공자: Higgsfield / `gpt_image_2_5`, high, 4k 요청, 3:2.
- 실제 반환 크기: 두 장 모두 **3504×2336**. ‘4k’는 요청 등급이며 가로 3840px 파일이 아니다.
- 사용량: 67 → 58.5크레딧, **실제 8.5크레딧**. 추가 구매·플랜 변경 없음.
- 원본 PNG는 `design/source-assets/visibility/`에 보존한다.
- 게임 파일은 동일 크기의 무손실 WebP다. PNG와 WebP의 디코딩된 RGBA 픽셀이 완전히 같은지 비교했다. 리사이즈·크롭·품질 저하는 하지 않았다.
- 통행 그림: 검문소·연락 장교·철도. 기지 그림: 계류 함정·급유 호스·정비 부두. 실제 전투 결과, 특정 함급의 고증 자료, 국경 통제 상태를 나타내지 않는다.
- 1936–1959년에만 노출한다. 현대·미래 화면에 1940년대 장비가 표시되지 않도록 그 밖의 연도에는 설명문만 남긴다. 이 시대들의 전용 기지 삽화는 이번 범위에 포함하지 않았다.

생성 프롬프트·작업 ID·파일 URL·비용은 `design/higgsfield-visibility-2026-09-23.json`, 크기·용량·SHA-256·무손실 검증은 `design/higgsfield-visibility-validation-2026-09-23.json`에 남겼다. `scripts/import-higgsfield-visibility.mjs`로 동일 자산을 검증할 수 있다.

## 인터랙션과 안전장치

- 작은 그림은 명시적 ‘확대 보기’ 버튼으로 열고, 확대 창은 원본 비율 `object-fit: contain`으로 표시한다.
- native dialog를 body에 포털로 표시하여 패널 잘림과 상속 CSS 충돌을 피한다. 배경 게임은 모달 동안 조작 불가다.
- 닫기 버튼에 첫 포커스, Esc로 닫기, 닫은 후 원래 그림 버튼으로 포커스 복귀를 확인했다. Tab은 브라우저 chrome로 이동할 수 있으나 뒤의 게임 조작에는 진입하지 않는다.
- 클릭·키보드 이벤트가 게임 명령으로 전파되지 않게 한다. 확대는 주차·자원·성과·저장 명령을 쓰지 않는다. 이미지 로드 실패 안내도 제공한다.
- 통행권 집행 전 검토에 들어가면 소개 삽화를 숨기고 대상·비용·확인 시점을 우선 표시한다. 실제 집행은 기존 별도 확인 버튼에서만 가능하다.
- ‘새 제안 작성’은 제안 양식으로 즉시 스크롤하고 포커스만 이동한다. 권한이 없어도 조건 조회는 가능하지만 제안·발효 권한을 부여하지 않는다. 선택·검토안·원장·자원을 바꾸지 않는다.
- React 검토에서는 이 읽기 전용 UI와 게임 상태 변경 경계를 우선 확인했다. 파일별 스타일 범위를 유지했으며 전역 테마는 바꾸지 않았다.

## 검증

- 최종 관련 UI: 8개 파일 **298개 테스트 통과**. 확대, 시대/키 방어, 명령 분리, 조직·조약 회귀, 제안 바로가기 포함.
- 별도 이동·해군 회귀: 5개 파일 **320개 테스트 통과**. 합계 서로 다른 13개 파일, **618개**.
- `npm run lint`, `npm run build`, `git diff --check` 통과. 전체 수만 개 테스트를 실행한 결과는 아니다.
- 로컬 `http://127.0.0.1:4197/`, 독립 브라우저 세션의 영국 최고 정치 보직 캠페인으로 검증했다. 기존 사용자 저장을 덮어쓰지 않았다.
- 통행권 화면 1920×1080 / 2560×1440 / 3840×2160에서 문서 가로 overflow 없음. 확대 원본 3504×2336, `contain` 확인.
- 검토 화면 1080p에서 삽화 0개, 대상·비용·두 검토 버튼이 화면 안에 표시됨. 집행하지 않고 검토·취소까지만 확인했다.
- 선택 참모 초상은 1080p에서 약 105.6px, 1440p·4K에서 112px. 일반 명단은 38px 유지. 해당 조직 화면 가로 overflow 없음.
- 1280×800 PC 작업공간에서도 지휘 그림 170px 유지, 가로 overflow 없음.
- 열람 전후 자원 표시와 캠페인 날짜 동일. 브라우저 오류 수집 결과 없음.
- 녹화는 로컬 `ffmpeg` 부재로 생성하지 못했다. 성공 화면 스크린샷을 증거로 남겼으며 영상 검증을 완료했다고 주장하지 않는다.

## 남은 한계와 배포 상태

새 그림 두 장의 런타임 합계는 약 17.5MB다. 사용자 요청대로 해상도/품질을 우선하여 원본 품질을 유지하고 lazy loading을 적용했다. 저속 네트워크 첫 열람에는 로딩 시간이 필요할 수 있다. 빌드의 기존 큰 JavaScript 청크 경고도 여전히 남는다. 모든 국가·모든 주차의 시각 회귀를 확인한 것은 아니다.

이번 변경은 로컬에 반영했다. 다른 작업의 수정은 보존했으며 **커밋·외부 배포는 하지 않았다**. 기존 통행권·해군 기지 엔진의 완성도를 확대 삽화만으로 보증하지 않으며, 외국 AI의 주둔 자동 생성 같은 추가 엔진 기능은 별도 범위다.
