# 지휘부 배치도 · 참모 업무표

## 구현 범위

지휘 본부 → 현장 보기 안에 `지휘부 배치도 / 참모 업무표 / 국가 현황`을 분리했다. 기존 세계지도, 지휘 데스크, 생산 배분 예상·승인, 국가 공급·보건 화면은 보존했다.

배치도는 현재 조직을 설명하는 탑다운 모식도이다. 국가 전체를 한 마을로 축소하거나 실제 지휘부 주소·건물·환자·사람 이동을 추정하지 않는다. 건설, 길찾기, 실시간 노동 시뮬레이션은 이번 구현에 포함되지 않는다.

- 8개 공간: 작전, 연구, 군수, 생산, 인사, 정무, 재정, 보건.
- 실제 참모 7개 보직을 해당 공간에 연결한다. 별도 의료 참모를 생성하지 않는다.
- 방 선택은 현황·권한을 읽는다. 인물 선택은 실제 초상·신원·보직·사기·부담·관계·현재 현안을 읽는다.
- 업무표와 검사창은 같은 실제 인사 상태를 편집한다.
- 책임 위임, 집중 육성, 면담, 승급·계약, 보직 교환은 기존 명령 함수와 검토서를 사용한다.
- 하단 행동 바는 선택한 방/참모와 현재 권한에 맞춘다.
- 생산실은 생산 작업대로, 군수실은 국정 단계의 집하·수송 작업대로, 인사실은 참모 스쿼드로 이동한다.
- 전후에는 안보 상황실·과학기술실·물류 조정실·산업전환실·공직 인사실 등의 이름이 된다.
- 현대의 단말기 외형은 시대 표현이다. 기술이나 능력 해금을 의미하지 않는다.

## 실제 주간 효과

참모별 선택값 `workPriority`는 기존 참모 저장 데이터의 선택 필드다. 과거 저장에서는 누락·잘못된 값을 통상 업무로 정규화한다. 두 주간 엔진 경로(전쟁/국정) 모두 같은 함수를 사용한다.

| 업무 방침 | 기존 주간 업무량 계산에 추가 | 기존 주간 성장도 계산에 추가 |
|---|---:|---:|
| 집중 업무 | +5 | +2 |
| 통상 업무 | 0 | 0 |
| 부담 경감 | −7 | −2 |

기존 위임·집중 육성·과부하 규칙 및 상하한을 포함해 미리보기를 계산한다. 조직 사건·면담에 따른 추가 변화는 별도다. 생산량·연구량을 직접 증폭하지 않으며, 임의 작업 대기열을 구현한 것처럼 표시하지 않는다. 높은 업무량은 기존 사기·충성도 계산에도 영향을 줄 수 있다.

## 안전장치

- 렌더링, 방 선택, 인물 선택만으로 비용이나 명령을 집행하지 않는다.
- 상급기관 관할 인물은 열람 가능하되 업무 속도·위임·육성·재배치를 제한한다.
- 진행 중, 해임, 민간 시작, 소속 불일치 등 기존 인사권 제한을 보존한다.
- 보직 교환은 양쪽 당사자·비용·적합도·위임·약속을 검토한 후 최종 승인한다.
- 검토 후 상태 변경·중복 승인·후임자 신원 변경을 기존 fingerprint/identity 검증으로 차단한다.
- 관계와 사건의 모든 당사자를 현재 명부의 고유 인물 식별자로 확인한다. A를 유지하고 B만 교체해도 이전 A–B 사건은 현재 현안에서 제외된다.
- 선택 인물이 교환되면 배치도 표식은 새 부서에 나타나며, 선택 검사창은 같은 실제 인물을 유지한다.

## 미술 제작

바닥 / 벽 / 문 / 가구 / 인물 표식 / 선택 UI를 분리했다. 8종 가구는 고유 SVG 레이어이며 장식용 `aria-hidden`과 포인터 비활성으로 실제 버튼을 가리지 않는다. 초상은 기존 실제 인물 초상 레지스트리를 사용하며, 없는 초상을 다른 사람의 얼굴로 대체하지 않는다.

새 바닥 자산: `src/assets/world-scenes/headquarters-floor.png` (내장 image_gen 사용, 기존 파일 비파괴 추가).

사용한 최종 프롬프트:

> Use case: stylized-concept. Asset type: seamless tileable game floor texture, used under functional rooms in an original historical headquarters top-down management game. Create one square orthographic texture of worn dark warm-grey stone/concrete square floor tiles, subtle joints, tasteful hand-painted tactile detail, soft neutral even lighting. Restrained charcoal olive-grey palette, low contrast so UI objects remain legible. Consistent tile sizes, seamless edges, absolutely straight top-down camera, no perspective. Entire image only floor surface. No furniture, no walls, no doors, no people, no objects, no labels, no text, no watermarks. This is a reusable material layer, not a scene or UI mockup.

## 검증 기록

- TypeScript 검사와 Pages용 빌드 통과. 기존 대형 번들 경고는 남아 있다.
- 최초 통합 실행: 12파일 264사례 중 263통과, 기존 인사 검토 반복 테스트 1개가 5초 제한시간 초과. 동시 실행 수를 2개로 제한한 동일 12파일 재검증에서 **264사례 모두 통과**했다. 테스트 자체의 제한시간은 완화하지 않았다.
- 격리된 로컬 브라우저 캠페인에서 8실·7명 표시, 담당자 선택, 부담 경감 지정 및 다음 주 전망 반영을 확인했다.
- 실제 확인 예: 앨런 브룩의 부담 경감 지정 후 부담 31 → 다음 주 기본 예상 25.5, 성장도 24 → 28.
- 실제 보직 교환: 앨런 브룩(작전참모장) ↔ 프레더릭 리더스(군수총감). 무료 검토에서는 배치가 바뀌지 않고, 영향 확인 체크 및 최종 승인 뒤 지휘실/군수실의 인물 표식과 보직이 서로 바뀌었다. 양쪽 위임 회수와 사기·만족 변화 영수증을 확인했다.
- 실제 다음 주 진행: 1942-10-25 → 1942-11-01. 교환으로 위임이 회수된 앨런 브룩의 부담은 예상대로 31 → 21, 성장도 24 → 25로 바뀌었고 부담 경감 방침도 유지됐다. 사기 77·충성 82.4의 실제 결산 수치를 확인했다.
- 조사(과/와) 마감 후 인사 UI 12사례 추가 실행도 통과했다(중복 제외 관련 테스트 총 265사례).
- PC 확인: 1920×1080 배치도, 2560×1440 업무표(7명), 3840×2160 배치도(8실) 모두 문서 가로 넘침 없음. 4K 육안 점검에서 발견된 가구의 방 바깥 돌출은 고정된 장식 프레임으로 수정했다.
- 브리핑의 ‘내 선택의 결과’에서 실제 `참모 업무 방침 — 앨런 브룩`, `참모 보직 교환 — 앨런 브룩` 기록을 확인했다.
- 화면 증거: `headquarters-1080p.png`, `headquarters-staff-1440p.png`, `headquarters-4k.png`.
- 수정 후 1080p와 4K에서 8개 가구 프레임 모두 방 경계 안에 포함됨을 DOM 좌표로 확인했다. 브라우저 페이지 오류 기록 없음. 최종 빌드 JS에도 `hq-room-furnishings` 수정이 포함됨을 확인했다.

로컬 주소는 `http://127.0.0.1:4197/`이다. 이번 작업은 로컬 구현이며 커밋·푸시·Pages 게시를 실행하지 않았다.
