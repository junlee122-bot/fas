# IRON DOMINION 225회 UX 플레이테스트 보고서

## 결론

현재 빌드의 가장 큰 문제는 콘텐츠 부족이 아니라 **주의 신호의 신뢰도와 주간 진행 동선**이다. 225회, 총 23,400주를 진행하는 동안 매주 평균 3.95개의 행동 알림이 발생했고, 전체 주의 86.3%가 긴급 상태였으며 권장 행동은 100%의 주에 남았다. 플레이어가 모든 시스템을 적극 관리한 경우에도 긴급 상태가 81.0%의 주에 나타났다. 이 때문에 긴급, 권장, 참고의 의미가 희석된다.

또한 104주 플레이 한 회마다 지난주 결과와 세계 주보를 확인하기 위한 주요 동선이 206회 발생한다. 전체로는 화면 이동 46,350회이며 실제 의사결정 34,484회보다 많다. 플레이어는 결정을 내리는 것보다 결정을 내리기 위한 화면 이동을 더 자주 수행한다.

## 테스트 방법

- 자동 플레이: 225회 × 104주, 총 23,400주
- 범위: 13개 국가, 169개 실제 선택 가능 보직, 5개 직급, 군사·정치·정보 3개 분야
- 플레이 성향: 안내 추종형, 빠른 진행형, 군사 집중형, 국가 운영형, 완주형 각 45회
- 연결한 실제 게임 로직: 캠페인 초기화, 보직·참모 구성, 생산, 연구, 지휘관 성장, 경제 결산, 통화, 시장 사건, 공중보건, 행동센터, 온보딩, 주간 지휘 사이클
- 실제 UI 검증: 로컬 빌드 `127.0.0.1:4180`, 1262×568 데스크톱 화면에서 캠페인 생성 → 튜토리얼 → 세계 주보 → 조직 운영 동선을 직접 재현
- 재현 코드: `src/playtestHarness.ts`, 검증: `src/playtestHarness.test.ts`, 집계 원본: `docs/ux-playtest-225-summary.json`

이 테스트의 225회는 실제 게임 엔진을 호출한 결정론적 자동 플레이이다. 225회를 모두 사람처럼 브라우저에서 클릭한 것은 아니다. 화면 배치, 문구, 포커스, 스크롤 문제는 대표 동선을 실제 UI에서 별도로 확인했다. 따라서 반복·경제·연구·행동 우선순위 수치는 전체 표본 결과이고, 화면 밀도 수치는 대표 UI 검증 결과다.

## 발견한 불편과 원인

### P0 — 완료할 수 없는 연구 긴급 알림

연구 프로젝트를 모두 끝내면 활성 연구가 0개가 되지만, 행동센터는 오직 `활성 연구 < 2`만 검사한다. 더 배정할 연구가 없어도 ‘연구 중단’ 긴급 항목이 계속 생성된다. 225개 모든 세션에서 발생했고 연속 반복 주 합계가 19,849주였다.

개선 방향:

- `미완료이며 배정 가능한 연구 수`를 함께 검사한다.
- 연구 트리를 모두 끝냈다면 긴급 알림 대신 ‘현재 연구 세대 완료’ 상태를 보여준다.
- 다음 시대 연구가 열리는 조건과 예상 시점을 한 줄로 제공한다.
- 회귀 테스트: 모든 연구 완료 후 `research-slot` 행동이 없어야 한다.

### P0 — 행동센터가 항상 붉다

전체 주의 86.3%가 긴급 상태이고 권장 행동은 100%의 주에 남았다. 완주형 사용자도 4,680주 중 3,791주가 긴급이었다. 장기적으로 플레이어는 배지와 색을 무시하게 되고 진짜 쿠데타, 전선 붕괴, 보건 재난을 놓치게 된다.

개선 방향:

- 행동을 단순 조건문 결과가 아니라 상태 기계로 관리한다: `발생 → 확인 → 조치 중 → 다음 결산 검증 → 해결/재발`.
- 조치 직후에는 같은 경고를 다음 결산까지 숨기고 ‘효과 관찰 중’으로 바꾼다.
- 같은 원인이 계속될 때는 새 알림을 만들지 말고 수치가 악화되었을 때만 재승격한다.
- 긴급은 ‘이번 주 미처리 시 비가역 손실’에만 사용하고 나머지는 권장 또는 참고로 내린다.

### P0 — 역할과 무관한 온보딩

전체 온보딩 완료율은 37.8%였다. 군사 집중형과 국가 운영형은 각각 자신의 분야를 충실히 관리했지만 완료율이 모두 0%였다. 현재 온보딩은 모든 역할에 ‘국가 원칙 4개’와 ‘첫 작전 명령’을 동시에 요구한다. 권한이 낮거나 정보·정치 보직인 플레이어에게도 최고 지휘관의 체크리스트를 강제한다.

개선 방향:

- 공통 3단계: 첫 브리핑 읽기, 권한 범위 확인, 다음 주 진행.
- 군사 보직: 부대 확인 → 작전 또는 훈련 명령 → 결과 검토.
- 정치 보직: 내각 관계 확인 → 예산·원칙 결재 → 지지 기반 변화 확인.
- 정보 보직: 정보망 확인 → 요원/작전 배치 → 신뢰도와 역정보 위험 확인.
- 4·5등급 보직은 직접 결정 대신 상신, 설득, 위임 요청을 가르친다.
- 목표: 안내 추종형 95% 이상이 10회 이내의 의미 있는 행동으로 완료.

### P0 — 주간 진행의 화면 이동세

2년 플레이에서 한 회당 결과 확인 103회와 세계 주보 103회가 주요 진행 동선에 들어간다. 225회 전체에서는 46,350회다. 정보 자체는 필요하지만 매주 서로 다른 전체 화면을 왕복해야 하므로 흐름이 끊긴다.

개선 방향:

- 대시보드에 ‘주간 지휘 브리핑’ 한 장을 둔다.
- 첫 영역에 지난 선택 3개와 결과, 두 번째에 세계 변화 3개, 세 번째에 이번 주 긴급 결재를 배치한다.
- 상세 기사와 전체 결산은 펼치기 또는 해당 부서 링크로 남긴다.
- `모두 읽음`이 아니라 실제 요약 카드를 화면에 노출한 뒤 한 번의 진행 동작으로 확인 처리한다.
- 권장 행동은 진행을 막지 않고, 긴급 행동도 명확한 위험 확인 후 우회 진행을 허용한다.

### P1 — 매주 되살아나는 ‘대기 부대’ 권장 행동

모든 225개 세션, 모든 23,400주에서 `idle-formations`가 반복되었다. 작전이 한 주 만에 해소되면 다음 주 바로 같은 권장 행동이 돌아온다. 방어 대기, 재편, 예비대 운용도 정상 전략인데 UI는 매주 미완료 업무처럼 취급한다.

개선 방향:

- 부대 의도를 `공세 준비 / 방어 / 예비대 / 훈련 / 재편`으로 명시한다.
- 아무 의도도 없는 부대가 2주 이상 지속될 때만 알린다.
- 같은 부대 경고에는 4주 쿨다운을 두되 전선 위험이 급변하면 즉시 재활성화한다.
- ‘모든 준비 부대에 명령’이 아니라 위험이 큰 전선과 명령 없는 부대를 구체적으로 지목한다.

### P1 — 경제 문제가 행동이 아니라 상시 배경 소음이 됨

모든 세션이 적자와 물가 경고를 경험했다. 적자 행동은 213개 세션에서 합계 15,279주, 물가 행동은 212개 세션에서 3,842주 연속 반복되었다. 정책을 바꿔도 다음 주 결산 전까지 같은 카드가 남고, 적자의 원인이 세입·공장·참모비·이자 중 무엇인지 행동센터만으로 알기 어렵다.

개선 방향:

- 행동 카드에 가장 큰 원인 1개, 정책 적용 예상치, 확인 예정 주를 표시한다.
- `정책 변경 완료 · 다음 주 예상 경상수지 +X` 상태를 별도로 둔다.
- 적자와 물가를 각각 카드로 쌓지 말고 ‘거시경제 압력’ 묶음으로 합친다.
- 금융조달을 경상수입처럼 보이지 않게 유지하고, 국고 고갈 예상 주와 부채 상환 부담을 함께 보여준다.

### P1 — 조직 운영 첫 화면의 정보·조작 밀도

실제 UI에서 조직 운영 화면은 버튼 230개, 링크 21개였다. 주 콘텐츠 스크롤 높이는 7,002px이고 실제 표시 영역은 436px로 약 16화면 분량이다. 좌측 내비게이션도 667px 콘텐츠를 241px 영역에 넣는다. ‘심층 검증 86명’ 후보군과 각 후보의 다중 조작이 한 화면 흐름에 연결되어 있어 FM식 선수단 관리보다 대형 데이터 입력 화면에 가깝다.

개선 방향:

- 기본 화면은 현재 참모 7명과 빈 보직만 보이는 ‘스쿼드 뷰’로 제한한다.
- 후보 시장은 별도 화면으로 분리하고 가상 스크롤, 검색, 분야·가용성·검증도 필터를 제공한다.
- 후보 행의 주 행동은 하나만 두고, 정찰·비교·협상은 상세 서랍에서 단계적으로 노출한다.
- 상단에 `직접 관리 / 위임 / 공석` 요약과 역할 권한에 따른 잠금 사유를 둔다.
- 목표: 첫 화면 상호작용 요소 35개 이하, 핵심 참모 배치가 1.5화면 안에서 완료.

### P1 — 튜토리얼의 목표와 이동 위치 불일치

실제 흐름에서 ‘참모와 인재가 전력을 만듭니다’ 단계의 호출 버튼이 ‘정보 부서 보기’로 나타나 조직 운영에서 정보 화면으로 이동했다. 사용자가 배워야 할 개념, 버튼 문구, 도착 화면이 다르다. 취임 직후에는 튜토리얼과 세계 주보 미확인 상태도 동시에 경쟁한다.

개선 방향:

- 튜토리얼 단계는 하나의 목표, 하나의 CTA, 하나의 도착 화면만 가진다.
- 도착 후 대상 컨트롤에 포커스를 옮기고 실제 한 번의 조작이 완료되어야 다음 단계로 간다.
- 취임 주에는 세계 주보를 튜토리얼 내부 브리핑으로 통합한다.
- 뒤로가기, 건너뛰기, ‘나중에 다시 보기’를 항상 같은 위치에 둔다.

### P2 — 문구·접근성 품질

취임 보고에 ‘버나드 몽고메리을 대신하여 버나드 몽고메리이(가)’처럼 조사 처리와 이름 중복이 확인됐다. 캠페인 설정이 열린 초기 접근성 트리에는 뒤쪽 대시보드 컨트롤도 함께 노출됐다. 모달 뒤 콘텐츠가 보조기술과 키보드 포커스에서 완전히 격리되지 않았을 가능성이 높다.

개선 방향:

- 한국어 조사 유틸리티를 사용해 `을/를`, `이/가`, `은/는`을 자동 처리한다.
- ‘대체 인물’과 ‘사용자 보직’의 이름을 분리해 같은 실존 인물이 두 번 출력되지 않게 한다.
- 설정·전투·위기 모달에 `role="dialog"`, `aria-modal="true"`, 포커스 트랩, 배경 `inert`를 적용한다.
- 핵심 취임·사건 문구를 국가/보직 전 조합 스냅샷 테스트로 검증한다.

## 권장 구현 순서

1. **신호 신뢰도 복구**: 연구 종료 오탐, 행동 상태 기계, 대기 부대 쿨다운을 먼저 고친다.
2. **역할별 첫 30분 재설계**: 보직 권한에 맞춘 온보딩과 취임 주 브리핑을 만든다.
3. **주간 허브 통합**: 결산·세계 주보·긴급 결재를 한 화면에 합친다.
4. **조직 운영 분할**: 스쿼드 뷰와 후보 시장을 분리하고 후보 목록을 가상화한다.
5. **정책 효과 설명 강화**: 재정·보건 카드에 원인, 예상 효과, 검증 시점을 붙인다.
6. **접근성·한국어 마감**: 모달 격리, 포커스, 조사 처리, 중복 문구를 자동 검증한다.

## 지속 검증 기준

- 완주형의 긴급 상태 비율 20% 이하
- 완료할 수 없는 긴급 행동 0건
- 같은 원인·같은 설명의 행동이 4주 넘게 반복되지 않음
- 안내 추종형 온보딩 완료율 95% 이상
- 역할 권한 밖의 필수 온보딩 0건
- 화면 이동:결정 비율 0.5 이하
- 조직 운영 첫 화면 버튼 35개 이하
- 캠페인 설정 및 모든 모달에서 배경 포커스 0건
