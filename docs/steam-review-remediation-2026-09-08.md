# 스팀 리뷰 개선 1차 — 규칙과 진행의 신뢰성

기준: `steam-review-2026-09-08.md` 및 이전 묶음에서 이어진 직업·전쟁·주간 흐름 개선 과제.

이번 묶음은 새로운 콘텐츠 개수보다 **내 행동이 실제 계산에 들어가고, 그 결과를 화면에서 확인할 수 있는가**에 집중했다. 리뷰 전체를 해결했다는 뜻은 아니다. 변경은 로컬 작업 트리에 적용했으며 이번 작업에서 커밋·원격 배포는 하지 않았다.

## 실제 브라우저 검증

주소: `http://127.0.0.1:4197/`. 기존 프시케용 4173을 사용하지 않았다. 별도 검증용 브라우저 세션에서 진행했으며 사용자의 일반 브라우저 저장을 건드리지 않았다.

1. 영국 군사 보직으로 새 게임 → 튜토리얼 8단계 → 창간호 열기. `Maximum update depth exceeded` 및 게임 실행 오류 없음.
2. 야전 훈련 → 병력·상태 변화 및 `왕립 기갑원정군 야전 훈련 집행` 증거 생성 → 저장 캠페인 재개 후 증거 보존. 메뉴 방문만으로는 목표 완료되지 않음.
3. 한 주 진행 → 통합 브리핑 → 닫기 → 미확인 유지 → 다시 열고 완료 → 다음 주 진행 버튼으로 변경.
4. 데스크톱 및 390×844 모바일에서 새 브리핑 확인. 모바일 창/본문의 `clientWidth=scrollWidth=372`, 결정 영역 `338=338`: 해당 창의 가로 넘침 없음. 본문은 세로 스크롤, 완료 버튼은 고정 영역에 유지.
5. 전후 테스트 저장을 준비해 9→10주 진행: 화면 연도 1943, 회사 9/9 가격 변경, `national-program:commonwealth-federation:milestone:6` 및 프로그램 결과 이벤트 생성.
6. 동시 전선 테스트 저장으로 1→2주 진행: 영불해협 상륙전 진척 38, 리비아 소모전 진척 39. 두 명령 모두 경과 1주, 각 병력 손실 4, 두 예상 대비 결과가 같은 주 결산에 포함. 수치는 이 실행의 난수 결과이며 고정 보장값이 아니다.

5·6은 긴 캠페인을 자연 진행한 기록이 아니라 **통합 경계조건을 검증하기 위해 준비한 저장 상태**다. 검증 후 테스트 세션의 원래 전쟁 저장을 복원했다. 이번에 1942~2060 장기 다회 시뮬레이션을 재실행했다고 주장하지 않는다.

## 자동 검증

- 최종 `npm test`: **85개 파일 / 522개 테스트 통과**.
- 최종 `npm run build`: TypeScript 및 프로덕션 빌드 성공.
- `git diff --check`: 공백 오류 없음. Windows의 기존 LF→CRLF 안내는 있음.
- 대형 JS 청크 경고는 여전히 남음. 지도 이미지의 해상도·용량은 낮추지 않았음.

React 검토 지침에 따라 튜토리얼 효과와 사용자 행동을 분리하고, 보직·개인생활 상태를 별도로 복제하지 않으며 기존 상태에서 UI를 계산했다. 새 브리핑은 모달 접근성, 명시적 확인, 모바일 세로 배치를 실제 화면으로 확인했다.

## 아직 남은 큰 과제 — 다음 묶음

1. **경제가 실제 생활과 정치를 바꾸게 하기**: 국민 집단·소비재 부족·가격·노동·산업 배분을 표시용 분석에 그치지 않고 주간 세입·불만·고용·정치 행동에 일관되게 연결. 이번 시장 갱신 복구가 이 전체 경제 순환의 완성을 의미하지는 않는다.
2. **인물 갈등의 원인을 실제 플레이 이력에 연결**: 자동 이야기 해시보다 작전 실패·보직 이동·약속 위반·언론 발언을 근거로 갈등과 장기 관계가 발생하도록 보강.
3. **직업별 다른 플레이 경험**: 민간 직업과 정보 커리어에 고유 활동·실패·복귀 경로를 더 깊게 연결. 보직 성과도 현재의 ‘조치 집행 증거’에서 지연된 결과·책임 평가로 발전시킬 필요가 있음.
4. **후반 의사결정 밀도와 사건의 우선순위**: 일반 보고·새로운 선택·위기를 더 엄격하게 구분. 첫 주부터 세계 체제 관련 보고가 많이 나오는 현상은 추가 조율 대상. 정례 보고 두 유형만 통과시키므로 모든 위임 중단 문제가 해결된 것은 아님.
5. **전후 국방·병기·합동군의 연속성**: 시장·프로그램 이외의 전시 전용 처리들이 국가 운영에서도 적절한 방식으로 이어지는지 후속 감사.
6. **시청각·콘텐츠 고증·구조적 성능**: 인물별 장면과 전용 사건 삽화, 지속 음향, 시대별 표현, 큰 App 상태 결합과 번들 분할은 이번 묶음에서 완결하지 않았음.

결론: 리뷰에서 확인된 규칙 불신과 진행 단절의 핵심 결함을 먼저 줄였다. ‘기능이 있다’보다 ‘사용자 선택이 실제로 계산되고 증거가 남는다’는 방향으로 다음 묶음을 이어간다.
