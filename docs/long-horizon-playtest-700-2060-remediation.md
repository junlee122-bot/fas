# 700회 장기 플레이테스트 개선 반영 보고서

## 결론

기존 700회·4,295,200주 원자료에서 확인된 P0/P1 문제를 게임 엔진과 UI에 직접 반영했다. 수정 후에는 정치·군사·정보 3개 계통, 6개 실제 보직, 6개 행동 성향을 고정 ID로 재현한 1942–2060 전체 기간 표본 6회(36,816주)를 다시 계산했다.

이 6회 회귀는 기존 700회를 통계적으로 대체하지 않는다. 목적은 수정된 코드가 118년 전체 구간에서 실제로 작동하는지, 기존 실패 신호가 같은 방식으로 재현되는지를 빠르게 검증하는 것이다. 전체 700회 재검증은 같은 실행기의 `--worker`와 `--merge` 경로로 다시 수행할 수 있다.

기존 보고서의 “연구 공백 65.5년”은 비연속적인 모든 비활성 주차를 합한 값을 공백으로 표기한 계측 오류도 포함했다. 새 분석기는 총 비활성률과 최장 연속 공백을 분리한다. 수정 후 최장 연속 연구 공백 중앙값은 2.7년이다.

## 실제 구현 내용

### 1. 2022–2060 연구 세대

- 행성보건, 초장주기 저장망, 회복형 반도체 생산망, 자율지휘 통제규약, 핵융합 실증, 양자보안, 체화형 AI, 달 물류, 기후개입 통제, 과학발견 공동지능, 우주 방어, 핵융합 전력권, 행성방위, 건강수명 사회계약까지 25개 연구를 선행조건 사슬로 추가했다.
- `planetary-age`, `synthetic-age` 시대를 연구 타입에 추가했다.
- 이전 저장 파일은 정규화 과정에서 새 연구를 자동 병합한다.

### 2. 2025–2059 역사 패턴 기반 가능세계

- 공공 연산 협약, 기후 손실 연대, 궤도 교통체제, 양자 전환 위기, 자율무기 협약, 고령사회 노동계약, 기후 이주 회랑, 핵융합 자원 협상, 달 공유지, 합성생물 사고, 탈탄소 무역질서, 물 분쟁기구, 알고리즘 헌정, 행성방위 협의회, 장수 분배, 행성간 관할권, 계획이주, 인간·기계 사회계약을 추가했다.
- 미래 사건은 사실 예언으로 표시하지 않고 `historical-pattern`으로 구분하며, 실제 국제기구와 역사적 제도의 기준선을 출처로 보존한다.
- 세계사 모달에서 “역사 패턴 기반 가능세계”임을 명시한다.

### 3. 전후 직무별 평시 전략작전

- 동원해제, 동맹 표준화, 평화유지, 군사고문단, 군비통제 검증, 비밀 연락망, 해협 초계, 확산방지, 재난 수송, 테러자금 추적, 사이버 방첩, 제한목표 연합작전, 선거 정보공간 방어, 분산기지 훈련, AI 지휘 감사, 무인전력 인간통제, 우주자산 회복, 합성신원 방첩을 추가했다.
- 모든 작전은 10–20주 동안 유지된다. 화면이나 지도로 이동해도 취소되지 않으며 중간검토와 최종 결과가 별도 기록된다.
- 직무 계통, 시대, 정치력, 국고, 지휘자원, 안보·외교 예산, 정보망과 외부압력이 성공 판정에 반영된다.

### 4. 1·5·10년 국가계획과 기간 진행

- 1년 문민통제, 5년 사회역량·과학산업·개방번영, 10년 국토회복·다원국가 계획을 추가했다.
- 계획 진척은 고정 이벤트가 아니라 복지, 교육, 산업, 제도, 불평등, 불안, 상대경쟁력, 인구·생태·패권 비용으로 매주 재계산된다.
- 국가 운영 화면에 1주·4주·13주 진행을 배치했다. 위기, 새 연구, 작전·계획 평가, 선거 단계, 세계사 분기가 나타나면 자동 정지한다.

### 5. 후기 국가 성과의 구조 비용

- 국가점수에 상대경쟁력, 제도노후, 인구압력, 생태압력, 패권유지비를 추가했다.
- 국내 지표를 모두 100으로 올려도 구조 비용을 무시하면 완전점수에 도달하지 않는다.
- 장기 계획 달성은 이 구조 비용을 실제로 완화하므로 단순한 영구 페널티가 아니다.

### 6. 시대별 선거 문법

- 1942–1949 신문·라디오, 1950–1979 대중정당·방송, 1980–2004 TV·여론조사, 2005–2029 플랫폼·데이터, 2030–2060 합성매체·신뢰인증으로 구분했다.
- 같은 행동도 시대에 따라 이름, 설명, 기세·투표율·신뢰 효과가 바뀐다.
- 후기에는 합성신원, 자동여론, 알고리즘 감사와 출처인증이 선거 승복의 핵심 위험으로 표시된다.

### 7. 인과 서명 기반 결말

- 기존 결말 가족 ID는 유지하되 국가, 실제 대체 보직, 최근 결정 주차, 국가계획 결과, 평시 전략작전 결과를 묶은 `outcomeId`를 생성한다.
- 같은 서술 결말 가족에 도달해도 다른 직무와 계획을 수행한 세계는 별도의 결과 정체성을 갖는다.

### 8. 장기 계측기 교정

- 연구 총 비활성 주차와 최장 연속 공백을 분리했다.
- 시대별 평시 전략작전 수를 별도 계측한다.
- 반복 알림은 4주 연속 노출 뒤 13주 검증 대기로 전환해, 같은 조건을 수천 주 동안 새 긴급 경고로 세지 않는다.
- `--ids`로 정치·군사·정보·성향별 고정 세션을 재현하고, `--reanalyze`로 기존 원자료를 새 분석 기준에 재집계할 수 있다.

## 남은 검증

- 표본은 코드 경로와 방향성을 검증했지만 13개 국가·169개 보직의 분포를 대표하지 않는다.
- 다음 전체 700회에서는 국가별 후기 연구 완료 시점, 군사·정보 작전 선택 편향, 미래 세계 위기의 범주 연속 발생, 결말 문장 중복률을 다시 확인해야 한다.
- 평시 전략작전은 군사·정보 계통에서 세션당 186–225회, 정치 계통에서 73회로 차이가 크다. 이는 직무 차이를 만드는 의도된 결과지만, 합동작전의 빈도와 보상은 전체 표본에서 추가 보정이 필요하다.
