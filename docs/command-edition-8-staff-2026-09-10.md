# Command Edition 8 — 참모 인사 검토실

작성: 2026-09-10. [CE7 국제 경력 연락실](command-edition-7-career-2026-09-10.md)의 후속으로 **참모 승급·재계약·보직 교환**을 검토 → 승인 → 실제 반영 확인으로 통일했다. 함께 발견한 전후 국가 운영의 참모 인건비 누락과 인사권 이탈 상태의 기존 행동 허점을 수정했다.

## 플레이어에게 달라진 것

| 업무 | 승인 전에 확인하는 내용 | 실제 반영 |
|---|---|---|
| 승급 | 전문 등급, 능력·잠재력, 육성도, 업무량·충성, 일시 비용과 지속 급여 | 정치력 8·국고 50 사용, 전문 등급 +1, 육성 0으로 초기화, 능력 최대 +4·잠재력 최대 +1, 충성 +5·업무량 +8, 주급 +1. 보직·인사권은 그대로. |
| 재계약 | 갱신 보너스, 잔여 계약에 추가될 104주, 새 주급, 사기·역할 만족 | 정치력 4와 갱신 보너스 사용, 기존 잔여 기간 +104주, 기존 주급의 108% 올림, 사기 +10·만족 +6·충성 +5. |
| 보직 교환 | 이동하는 두 사람의 보직·적합도·위임·육성 대상·임명 약속 | 두 사람의 신원을 보존하면서 보직 교환. 일시 비용·전체 급여는 그대로. 두 사람의 위임 회수, 교환 대상에 있던 집중 육성 지정 해제. |

금액은 표에서 내부 회계 단위다. 화면은 해당 국가·시점의 화폐로 환산한다. 검토서의 환산 표기는 검토 당시 값으로 고정한다. 전문 등급의 3단계와 플레이어 보직의 5성 직급은 서로 다른 체계임을 표시한다. 이번 작업에서 참모 등급을 새로 5단계로 바꾸지는 않았다.

승급은 육성도 100·등급 3 미만, 재계약은 남은 계약 52주 이하일 때만 가능하다. 기존 UI에서만 막던 재계약 제한을 엔진에도 적용해 반복 갱신으로 충성을 올리는 우회를 막았다. 누락된 사기·만족도는 기존 정식 계산 함수로 복원하며, 기존 저장의 높은 능력치가 승급 때문에 내려가지 않는다.

계약이 0주가 되어도 자동 퇴직하는 현행 규칙은 바꾸지 않았다. 직무·급여는 유지되고 주간 처리에서 위임 회수·사기 하락이 발생한다는 안내를 추가했다. 보직 교환은 새 인물 영입이나 해임이 아니며, 기존 임명 약속과 성장 진행도는 유지된다. 교환으로 약속 위반이 생길 수 있고, 해당 참모가 담당하던 미완료 납품 약속은 종료될 수 있음을 설명한다.

## UI와 안전성

- 명단·개인 관리, 분위기·계약, 보직 배치의 기존 버튼을 같은 인사 검토서로 연결했다.
- 주요 수치를 먼저 비교하고 보조 상태는 펼쳐 읽도록 구성했다. 모바일에서는 두 인물 비교가 세로로 쌓인다.
- 교환은 두 사람의 변화 확인 체크 후 승인한다. 검토·취소·인물 열람에는 비용이 없다.
- 선택한 인물이 사라지면 첫 번째 인물로 자동 대체하지 않는다. 동일 슬롯의 다른 인물로 교체돼도 기존 검토서를 사용할 수 없다.
- 주차·자원·경력·소속·명부·계약·육성 대상이 달라지면 재검토한다. 승인 직전 재검증하고 같은 상태에서 재진입·중복 제출을 막는다.
- 네 가지 실제 상태—참모/보직/계약/위임, 국가 자원, 집중 육성, 소속/보직/조직 체계—를 비교한다. 콜백 호출만으로 완료라고 표시하지 않는다.
- 승인 후 다음 주로 넘어간 기록은 ‘반영 확인 중’이 아니라 ‘승인 이후 상태 변경’으로 안내한다.
- 검토서 전체를 스크롤 대상으로 삼아 고정 위기 배너가 제목·닫기 버튼을 가리던 문제를 수정했다. 숫자의 부동소수점 꼬리는 설명에서만 정리하고 실제 계산 정밀도는 보존한다.
- 해임·무소속·공식 보직 미취임 일반인은 인사권 없음으로 표시한다. 승급·재계약·배치 외 기존 면담·위임·육성·후보 조사·접촉·영입에도 App 공통 현직 검사를 적용했다. 기존 명부와 후보 보고서 열람은 유지한다.
- 새 캠페인·저장 복원·소속 이동에서 인사 승인 잠금을 초기화한다. 저장 버전은 **38**을 유지한다.

## 전후 급여 결산 누락 수정

전시 경제에는 참모 급여가 반영됐지만, 전후 국가 운영의 전망/실제 주간 계산에는 전달되지 않고 있었다. 두 경로에 현재 명단의 주급 합계를 전달하고 메모·진행 콜백의 의존성에도 반영했다.

급여는 **총지출에 한 번 포함**하며 별도로 국고에서 재차 빼지 않는다. 재계약 보너스는 승인 시점의 일시 비용이고, 이후 결산에서는 새 주급만 사용한다. 국정 예산·실제 결산·진행 설명에 현재 통화로 인건비를 표시한다. 기존 보고서에 인건비 필드가 없다면 추정값을 꾸며서 표시하지 않는다.

선택적 `staffWeeklyCost`를 전달하지 않는 기존 독립 시뮬레이션은 호환성을 위해 0을 사용한다. 따라서 과거 수천 회 보고서가 이번 급여 수정까지 재검증했다고 주장하지 않는다.

### 자연 진행: 영국 4성 군사 보직

새 캠페인에서 헤이스팅스 이즈메이를 집중 육성 대상으로 지정하고 실제 화면으로 4주 진행했다. 초기 주차 0은 화면 제1주다.

| 확인 | 관측 |
|---|---|
| 육성 | 주차 0의 육성도 72가 주차 3에 100이 됨. 상급기관 관할 과학·경제 참모의 인사 행동은 잠겨 있음. |
| 오래된 검토 | 주차 3에 승급 검토서를 열고 주간 브리핑 확인 후 주차 4로 진행. 기존 최종 승인 버튼 비활성화. |
| 새 검토·승급 | 주차 4에 재검토하고 승인. 정치력 124→116, 국고 931.9→881.9, 전문 등급 1→2, 육성 100→0, 능력 84→88·잠재력 88→89, 주급 8→9. |
| 보직 교환 | 앨런 브룩(작전)과 이즈메이(인사)를 교환. `id`/`personId` 유지, 각각 인사/작전으로 변경, 두 사람 위임 false, 집중 육성 null. 국고·정치력·전체 주급 61 유지. |
| 결과 확인 | 승급·교환의 실제 상태 확인 표시 및 자동 저장 값을 비교. 모바일 확인 체크 전에는 교환 승인 비활성화. |

### 통제된 저장본: 전후 지도자·해임 상태

자연 진행 저장본을 복제해 **영국 최고 정치 보직과 전후 phase로 설정**했다. 이는 정상 전쟁 종결·승진을 플레이한 기록이 아닌, 후반 상태를 빠르게 검증하기 위한 별도 테스트 조건이다. 결과 수치를 미리 주입하지 않고 이후 행동과 결산은 실제 UI로 실행했다.

| 확인 | 관측 |

| 케인스 재계약 | 남은 계약 15→119주, 주급 10→11, 사기 78→88, 역할 만족 82→88. 정치력 116→112, 국고 881.9→747.9(보너스 134), 전체 주급 61→62. 네 상태 모두 반영 확인. |
| 전후 다음 주 | 실제 버튼으로 주차 5 진행. `staffWeeklyCost=62`, 세입 55.9, 지출 110.4, 수지 −54.5. 국고 747.9→693.4. 급여는 총지출에 포함되며 별도 재차 차감 없음. |
| 기록 상태 | 주간 진행 후 인사 기록의 실제 상태는 더 이상 승인 직후와 동일하지 않음. 이를 처리 대기와 구분하도록 후속 문구 수정·회귀 테스트. |
| 해임 | 별도 테스트 저장본의 소속을 dismissed로 설정한 뒤 실제 로더로 복원. 참모 전원 열람 상태, 면담·위임·육성·승급·재계약 잠김. 후보 보고서는 열리지만 조사·접촉·관심 등록·협상 버튼 비활성화. |

## 다음 범위

참모의 기존 면담·위임·집중 육성은 권한 검사만 보완했으며 아직 동일한 사전 비교/승인 기록 구조로 전부 전환하지 않았다. 면담 결과와 장기 관계, 비밀 소속의 실제 임무·태세·사건 대응이 다음 인사/경력 묶음이다. 인사 외 다른 국가 행동의 해임 상태 권한·메뉴 표현도 별도 교차 감사 대상이다. 공통 번들·CSS가 큰 구조와 장기 플레이의 실제 재미 검증은 계속 남아 있다.

이번 작업은 새 역사 자료 조사나 대규모 장기 시뮬레이션이 아니다. React 스킬을 따라 파생 계산·순수 결정·명시적 집행을 분리했고, 브라우저 검증 스킬을 따라 화면과 실제 저장 결과를 함께 확인했다. 지도 이미지의 해상도·용량은 줄이지 않았다. 커밋·GitHub Pages 배포는 사용자 선호대로 GPT-5.6 Luna가 담당한다.
