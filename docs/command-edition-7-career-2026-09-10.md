# Command Edition 7 — 국제 경력 연락실

작성: 2026-09-10. [CE6 후보 시장](command-edition-6-personnel-2026-09-10.md)의 후속으로 **사용자에게 오는 제안 → 조건 탐색·재협상 → 승인 → 실제 이직 또는 비밀 소속**을 정리했다. 참모 후보 영입과 사용자 본인의 경력 이동은 서로 다른 업무공간으로 유지한다.

## 플레이 흐름

| 단계 | 이번 변경 |
|---|---|
| 받은 제안 | 제안별 신원·보직·기한·조건을 선택해 읽는다. 선택한 제안이 없어져도 다른 제안을 자동 승인 대상으로 대체하지 않는다. |
| 직접 접근 | 공식 지원, 비공식 어필, 망명 요청, 기밀 접근권 제시, 이중간첩 역제안의 다섯 경로를 고른다. 정치력 2와 신임·노출 변화를 먼저 검토한다. |
| 접촉 판정 | 회신 성공률은 공개하지만 실제 회신 여부는 승인 전 노출하지 않는다. 실패해도 정치력과 접촉 위험이 반영된다. 국가·방식을 바꿔도 2주 대기는 유지된다. |
| 탐색·재협상 | 각각 제안당 한 번만 가능하다. 탐색은 신뢰도와 노출을 바꾸며, 재협상은 계약금·보호 지수와 마감 2주 연장을 바꾼다. 실제 보직 권한과 연결되지 않던 권한 숫자 보너스는 제거했다. |
| 최종 검토 | 응답 6종과 접근 5종 모두 검토와 집행을 분리한다. 뒤로 가기·선택·읽기에는 비용이 없다. |
| 결과 확인 | 실제 경력 시장·국가 자원·소속/보직/평판/신임의 세 상태가 예상 결과와 일치할 때 확인 완료를 표시한다. 콜백 호출만으로 성공했다고 하지 않는다. |

받은 제안을 **수락**하는 행동은 기존 엔진에서 확률 추첨이 아니다. 추가 수락 확률처럼 보이던 안내를 제거했다. 반면 직접 접촉의 회신 판정은 별도 규칙이며, 정수 난수 판정과 표시 성공률을 일치시켰다. 같은 주차·국가·접근 방식의 판정은 저장을 다시 불러와도 동일하다.

## 공식 취임과 비밀 계약의 차이

정식 외국 보직은 새 국가의 기본 자원을 인수한 뒤 계약금과 수락 효과를 적용한다. 기존 국고에 계약금만 더하는 행동이 아니다. 검토 화면에 새 보직, 자원 전후, 인계할 참모·후보·부대·생산·외교·경제·보건·국정 체계, 신임 재설정과 경험 55%(반올림·최소 12)를 명시한다. 주차·세계선·선택·지도와 연구 목록/진행도는 유지한다.

공식 보직에 실제로 지급되지 않는 주간 비밀수당은 새 제안에서 0으로 만들고, 구 저장의 같은 항목도 지급 예정으로 안내하지 않는다. 계약금과 검토 자원은 **검토 당시 통화 환산액**으로 고정해, 이적 후 국가 화폐가 바뀌어도 과거 검토서의 숫자가 다른 화폐로 둔갑하지 않게 했다.

비밀 협조 수락은 현재 국가·보직을 유지한다. 정치력 4, 즉시 계약금, 신임·노출 변화와 다음 주간 처리의 비밀수당을 구분한다. 이미 비밀 계약이 있으면 연락관·임무·작전 자금이 새 계약으로 교체된다는 경고를 표시한다. 두 종류의 수락 모두 인계/위험 확인 체크 후 최종 승인한다.

‘포섭 연락망 역이용’은 기존 엔진의 방첩 효과와 기록을 남기는 대응이다. 새 이중간첩 임무를 만든다고 잘못 안내하지 않는다. 실제 비밀 소속 계약과 임무 운영 화면은 별도로 유지한다.

## 안전성·일반인 경력

- UI와 App이 같은 순수 결정 계층을 이용해 자격·비용·인계 결과를 계산한다.
- 마감 주까지 회신할 수 있고 다음 주부터 만료된다. 엔진은 0부터, 화면은 제1주부터 계산한다.
- 정치력 부족, 잘못된/중복된 제안, 알 수 없는 국가·보직, 잘못된 숫자, 진행 중 시간 이동, 부적절한 정보 권한과 해임 상태를 검사한다.
- 검토 후 상태가 바뀌거나 이미 제출한 검토면 승인하지 않는다. 현재 상태가 반영되기 전 다른 요청의 재진입도 막는다.
- 시작·저장 불러오기·초기화 때 승인 잠금을 초기화한다. 국가 이동 중에는 중복 승인 방어를 유지한다.
- 기존 저장의 탐색/협상 상태로 사용 횟수를 추론한다. 선택적 횟수 필드를 추가했으며 저장 버전은 **38**을 유지한다.
- 정식 보직뿐 아니라 정상 일반인 합성 역할도 검증한다. 13개국×12개 직업을 시험하며 임의의 잘못된 역할이 기본 보직으로 대체되지는 않는다.
- 일반인이 외국 정식 보직에 취임하면 민간 출신 기록을 유지하면서 `enteredOfficeRoleId`와 제도권 단계를 갱신한다. 새 보직 권한이 적용된다. 비밀 계약만 맺으면 시민 권한을 유지하며 추가 진입 보상은 중복 적용하지 않는다.

## 최종 검증

- `npm test -- --maxWorkers=2`: **124개 파일 · 1,774개 테스트 통과**, 110.20초. CE6 대비 195개 증가했다.
- 이번 관련 검사: 경력 시장 79개, 결정 계층 67개, 화면 62개. 일반인 경력·복원·재진입·만료·비용·실제 상태 확인을 포함한다.
- `git diff --check` 통과. 기존 LF/CRLF 정규화 경고 외 변경 오류는 없다.
- `npm run build:pages`: TypeScript와 Vite 빌드 통과(1,980개 모듈, Vite 5.48초). 경력실은 JS 47.53kB(gzip 14.05kB), CSS 17.32kB로 지연 로딩한다.
- 큰 청크 경고는 남는다. 메인 JS 3,126.43kB(gzip 983.40kB), 공통 CSS 871.83kB. 고해상도 극동 지도 22,370.07kB는 그대로 유지했다.

커밋·배포는 기존 사용자 요청대로 GPT-5.6 Luna가 기존 브랜치와 GitHub Pages 워크플로를 사용한다. 이번 소스·테스트·보고서·실제 확인 화면만 포함하며 무관한 원자료나 과거 이미지는 제외한다.

## 다음 범위

이번 묶음은 국제 경력 계약의 판단과 결과 확인에 집중했다. 비밀 임무 내부의 원클릭 대응·사건 대응·태세 전환, 실제 참모의 승급·재계약·배치 변경은 같은 검토/승인/검증 구조로 옮길 후속 대상이다. 상대국 인사·협상 AI, 장기 관계 장면, 큰 공통 번들/CSS와 지연 로딩 성능도 남아 있다.

새 역사 자료를 조사하거나 수천 회 장기 시뮬레이션을 수행한 작업은 아니다. React 스킬의 파생 상태/실행 분리 원칙과 브라우저 검증 스킬의 실제 저장 결과 검증을 적용했다. 지도 이미지의 용량·해상도는 줄이지 않았다.
