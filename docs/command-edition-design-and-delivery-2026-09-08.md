# Command Edition — 디자인 재구성과 다음 플레이 묶음

2026-09-08 · 로컬 개발 주소: http://127.0.0.1:4197/

## 이번에 구현한 범위

설계만 작성하지 않고 공통 화면 틀, 시작 화면, 지휘 데스크를 재구성했다. 이전의 active-world 설계를 이어 산업 자동 수송(C3)과 담당자별 정량 납품 약속(B2)을 실제 주간 엔진·저장에 연결했다. 원래 게임의 국가·보직·저장 데이터와 지도 원본 이미지는 유지한다.

### 화면 디자인

- 차콜 배경, 밝은 문서형 핵심 결정, 절제된 황동 강조색으로 공통 디자인 토큰을 새로 정의했다.
- 시작은 국가 → 삶·보직 → 최종 취임의 3단계다. 13개 진영, 군사·정치·정보 보직, 12개 민간 직업, 출신 배경, 한국 독립운동 안내와 저장 이어하기를 유지한다. 실제 게임 시작은 마지막 확인에서만 일어난다.
- 지휘 본부를 지휘 데스크 / 현장 보기 / 상세 분석으로 분리했다. 전후의 상세 분석은 기존 국정 화면으로 명확히 이동한다. 전체 분석과 현장 장면을 첫 화면에 동시에 쌓지 않는다.
- 지휘 데스크는 직접 권한 안의 우선 결정, 이번 주 임무, 진행 중 업무, 최근 기록 순으로 구성했다. 예하 지휘관의 부대 업무는 클릭 후 추적 메시지에도 예하 범위 문구를 유지한다.
- 상단 보직·정치·보건·주보 정보는 펼침 메뉴, 좌측 기록·저장·설정은 접이식 도구함으로 옮겼다. 핵심 내비게이션과 본문 공간을 확보한다.
- 상단 자원은 6개 항목을 재배치하고 좁은 화면은 2행으로 전환한다. 모바일은 우선 자원 3개와 전체 현황 버튼을 제공한다. 긴 화폐 값과 설명을 무조건 잘라내지 않는다.
- 모바일에서도 현재 날짜를 표시한다. 공간상 숨긴 시간 조절은 펼침 메뉴에서 다시 접근할 수 있다.
- 신규 주요 본문은 16px, 조작·라벨은 14px, 메타 정보는 12px를 중심으로 사용한다. 공통 레거시 본문도 가독성을 올렸지만 모든 기존 화면의 고밀도 표·지도 표기가 이 크기로 통일된 것은 아니다.

신규 스타일은 `src/design-system.css`에 별도로 두었다. 기존 CSS와 세이브 구조 전체를 위험하게 지우지 않고 `.design-v2` 아래에서 명시적으로 적용한다.

### C3: 승인된 자동 수송

- 기본은 수동이다. 주당 장비 수량 상한과 최소 창고 잔량을 입력하고 결재해야 자동 예약된다.
- 주간 결산은 기존 운송 진행 → 새 생산 집하 → 자동 출발 예약 순서다. 새 생산을 같은 주에 도착시킬 수 없다.
- 기존 수동 예약이 먼저 역량을 사용한다. 같은 주 중복 호출은 자동 예약을 추가하지 않는다.
- 적체 중 경로·품목·운영 모드는 잠그되, 동일 경로의 귀속 역량과 자동 지시 수치는 조절할 수 있다.
- 권한·경로 상실은 자동 예약을 보류한다. 자동 예약 중지는 이미 예약·운송 중인 화물을 취소하지 않는다.
- 실제 자동 예약 성공과 도착은 국가가 표시된 주간 기록으로 남긴다.

현재 수송은 고정 최소 2번의 주간 경계와 게임 화물 역량을 사용하는 추상화다. 실제 도로망·운송 요금·생산 lot 출처 추적을 새로 구현한 것은 아니다.

### B2: 참모 납품 약속

- 산업 화면의 별도 작업대에서 실제 관리 담당자, 기존 생산라인, 목표량, 2/4/8주 검증 기간을 선택한다.
- `공장 생산 완료`와 `국가 가용 새 편입`은 다르다. 전자는 실제 생산 완료, 후자는 신규 직납과 실제 운송 도착만 집계한다. 창고에 쌓인 양은 국가 가용 목표에 포함하지 않는다.
- 국가 가용 목표는 기간 내 입고 목표다. 이전에 생산해 창고에 보관했던 물건이 기간 중 도착하면 포함된다. 특정 생산라인의 원생산 lot을 증명하는 기능이라고 표시하지 않는다.
- 약속 생성 주가 아닌 다음 주부터 기한까지 실제 영수증을 모으며, 기한에 담당자 동일성을 다시 검증한다. 목표를 미리 채워도 즉시 성공 처리하지 않는다.
- 같은 사람·생산라인의 열린 약속을 중복 생성할 수 없다. 후임에게 약속을 자동 승계하지 않으며 퇴임·담당자 교체·국가 이동은 검증 불가로 종료한다.
- 공장 배정이 0이 되어도 생산라인의 정체성은 유지한다. 휴업했다고 약속이 사라지거나 임의 성공하지 않는다.
- 예측·열람·입력은 실행이 아니다. 이번 단계는 이행 기록 기능이며 추가 재정 비용, 정치력·사기 보상, 벌점은 없다. 약속만 만들고 성과 보상을 얻을 수 없다.
- 저장 버전 38. 이전 저장은 빈 약속 목록으로 시작한다. 동일 영수증·미래 영수증·미래 완료 시점 등 불일치를 검증하고 진단 기록을 남긴다.

## 검증 결과

- 전체 자동 테스트: **105개 파일, 801개 통과**.
- TypeScript 및 프로덕션 빌드 통과.
- `git diff --check` 통과. Windows의 LF/CRLF 안내는 존재한다.
- 브라우저 콘솔 오류 없음(확인한 시작·지휘·산업 흐름).
- 1440×1000, 1280×900, 390×844에서 시작/지휘/산업 화면 확인. 확인 화면에서 문서 가로 넘침 없음. 모바일 납품 작업대의 버튼·입력·본문이 화면 가로 경계를 벗어나지 않음을 계측했다.
- 1280px에서는 상단 140px와 본문 시작점 140px가 일치하며, 메뉴를 접으면 본문 왼쪽이 0으로 이동하고 메뉴는 inert 처리된다.
- 시작 모달 뒤에는 게임 조작 버튼이 인터랙티브 목록에 노출되지 않았다. 단계·분야 탭·키보드 포커스는 컴포넌트 테스트로도 확인했다.
- 브라우저 검증 중 발견한 모바일 진행 버튼의 세로 줄바꿈과 자원 설명 과밀을 수정했다.

### 실제 UI로 진행한 수송 → 약속 검증

테스트용 한국/조선 건국 이후 저장본을 사용했다. 두 인접 지역의 소유권과 자원을 QA용으로 설정한 픽스처이며, 정상 역사 캠페인의 자연 전개를 재현했다고 주장하지 않는다. 원래 로컬 저장은 사전 백업 후 전부 복원했다.

UI에서 경성 → 부산, 보병 장비, 귀속 역량 2, 주당 자동 예약 5개, 최소 잔량 10개를 결재했다. 김규식에게 국가 가용 새 편입 5개 / 4주 약속을 기록했다.

| 엔진 주차 | 첫 수송 상태 | 약속의 실제 가용 입고량 | 약속 상태 |
| --- | --- | ---: | --- |
| 1 | 5개 예약, 남은 유효 진행 2주 | 0 | 진행 중 |
| 2 | 운송 중, 남은 1주 | 0 | 진행 중 |
| 3 | 최초 5개 도착 | 5 | 기한 검증 대기 |
| 4 | 두 번째 5개 도착 | 10 | 목표 충족 |

- 기한에 실제 배송 영수증 2건으로 확정하고 달성 이벤트 1건을 남겼다.
- 자동 예약 중지 후 기존 예약 1건과 운송 1건이 유지됐다.
- 저장 후 다시 들어가도 완료 상태·영수증 2건·달성 이벤트 1건이 유지되어 재집계되지 않았다.
- 적체 중 경로 fieldset은 비활성, 역량 입력은 활성 상태임을 실제 DOM으로 확인했다.

자동 테스트 수는 사람의 수동 플레이 횟수가 아니다. 이번 턴에 수백·수천 캠페인을 새로 돌린 것은 아니다.

## 다음 디자인 묶음

> 후속 진행: 아래 1·2의 조직/국정/재정 화면 개편과 안전한 검토·확정 동선은 [Command Edition 2 구현·검증 기록](command-edition-2-management-and-finance-2026-09-08.md)을 참고한다. 모든 기존 세부 보드까지 재작성한 것은 아니다.

이번 변경은 공통 틀과 핵심 진입 흐름의 재구성이다. 모든 세부 화면을 처음부터 다시 작성했다고 볼 단계는 아니다.

1. 조직 운영을 인물 중심의 스쿼드 / 후보 시장 / 면담 / 이행 기록으로 일관되게 재배치한다. 현재 별도 산업 약속을 면담의 실제 안건으로 연결하되 임의 능력치 보상은 만들지 않는다.
2. 국정·재정을 분야별 패널 목록에서 이번 달 목표 / 정책 선택 / 결과 추적으로 재구성한다. 기존 계산과 권한 제한을 보존한 채 표와 카드의 중복 설명을 줄인다.
3. 작전·현장 장면은 새 팔레트에 맞추고, 지도·부대·산업 실제 상태를 같은 시각적 어휘로 연결한다. 고해상도 지도 원본은 유지한다.
4. 페이지별 책임을 App 밖으로 분리하고, 오래된 전역 CSS를 화면별로 단계적으로 대체한다. 현재 큰 JS/CSS 청크 경고는 남아 있다. 이미지 품질 저하로 이 문제를 덮지 않는다.

React 품질 점검에 따라 표시용 초안과 실제 결재를 분리하고, 원본 상태에서 파생 가능한 내용은 추가 게임 상태로 복제하지 않았다. 브라우저 검증을 통해 접근성·반응형 문제를 실제 화면에서 수정했다. 이번 턴에 커밋·배포는 실행하지 않았다.
