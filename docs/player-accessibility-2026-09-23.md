# 처음 들어온 사용자를 위한 플레이 체계 정리

## 한 문장으로 설명하는 게임

국가 전체를 무조건 조종하는 게임이 아니라, 한 사람의 지위와 권한에서 출발해 사람·정책·작전을 선택하고 그 결과로 역사가 달라지는 게임이다. 처음부터 모든 메뉴를 읽거나 모든 분야를 관리할 필요는 없다.

## 기본 순환

**세계와 내 역할을 읽는다 → 권한 안의 업무 하나를 검토한다 → 조건을 확인하고 선택한다 → 주간 진행 후 결과를 비교한다.**

| 시작 경로 | 처음 살펴볼 일 | 넘어가지 말아야 할 권한 경계 | 결과 확인 |
| --- | --- | --- | --- |
| 군사 | 편제·합동작전의 예하 부대 준비 상태 | 하급 지휘관도 예하 명령은 가능하나 전국 병력을 지휘하지 않음 | 작전 진행·중단 사유와 주간 결산 |
| 정치 | 참모 스쿼드와 담당 부서 | 정책별 직접 담당·상신·보고 구분 | 인사·정책 기록과 주간 영향 |
| 정보 | 정보망과 노출 위험 | 정보·인사 권한과 작전 조건 별도 확인 | 활동 기록·노출·접촉 결과 |
| 일반인 | 시민 활동실의 개인 활동 | 공식 국가 집행 권한 없음, 제도권 진입은 선택 | 개인 활동 기록·생계·평판·감시 |

현재 위임이나 보직 변경이 있으면 실제 `roleMandates`를 우선한다. 직급 숫자만으로 결재권을 추정하지 않는다. 높은 지위에서도 분야별 검토·비용·승인 조건을 생략하지 않는다.

## 기능 체계

- **사람과 조직:** 참모 배치, 후보 조사·영입, 면담과 후속 확인.
- **현장과 작전:** 지리·통제 지도, 예하 편제와 합동작전, 정보 활동.
- **국가와 사회:** 제도·재정·보건, 외교·조약·통행·기지권.
- **생산과 기술:** 연구·장비 개발, 생산·비축·수송. 연구 완료와 실전 배치는 다른 단계.

안내는 각 업무의 **하는 일 / 현재 권한 / 결과 확인 방법 / 이동 버튼**을 분리한다. 직접 담당·상신·보고·잠금은 색뿐 아니라 글자로도 표시한다. 잠긴 분야는 설명을 읽되 실행하거나 화면에 진입시키지 않는다.

## 이번 구현

1. **취임 전 미리보기:** 국가·직함 다음에 역할별 첫 플레이 3단계를 보여준다. 선택이나 취임을 대신 실행하지 않는다.
2. **첫 화면:** 첫 2주 동안 간단한 플레이 순환과 ‘내가 할 수 있는 일’ 진입점을 보여준다. 이후에도 상단 ‘할 수 있는 일’과 `?`로 다시 열 수 있다.
3. **플레이 안내:** 기존 야전 교범을 ‘시작과 할 수 있는 일 / 첫 주 체크리스트 / 시스템 교범’으로 나눈다. 기본 화면에서 짧은 순환부터 읽고 필요할 때 분야를 펼친다.
4. **튜토리얼:** 보직 5단계·민간 4단계. 현재 지휘 데스크를 실제로 가리키며 공통 첫 행동 문구를 재사용한다.
5. **잘못된 의무 제거:** 모든 역할에 빈 연구 슬롯을 채우라고 요구하지 않는다. 정치 3급 재정은 실제 상신 상태로 설명하며 하급 군사·정보 보직을 무조건 상신 전용으로 안내하지 않는다.
6. **이동 정확성:** 군사 첫 행동은 편제·합동작전, 조직은 참모 스쿼드처럼 정해진 하위 화면으로 연다. 주보·브리핑 체크리스트는 실제 해당 창으로 연결한다.
7. **읽기 안정성:** 안내를 열면 자동 속도를 멈춘다. 기간 위임 중에는 기존 기록 검토와 같은 중단·결산 경로를 사용하며 닫는 것만으로 자동 재개하지 않는다. 키보드 포커스가 안내 안을 순환하고 닫으면 트리거 또는 본문으로 돌아간다.
8. **민간 권한 문구:** 일반인에게 보직의 인사권·직접 지휘라고 표시하던 부분을 ‘공식 국가 권한 없음’과 ‘개인 활동’으로 구분한다. 실제 권한 판정은 그대로 유지한다.

안내 버튼은 시뮬레이션 실행 함수를 받지 않는다. 명시적 화면 방문은 기존 방문 기록만 남길 수 있으며, 실제 행동 근거·보상·경보 해결을 대신 만들지 않는다. 저장 스키마, 비용 계산, 역사 판정, 명령 승인 규칙은 바꾸지 않는다.

## 검증 및 다음 단계

권한 모델·역할별 안내·민간 잠금·콜백 분리·키보드·설정 단계·기존 지휘 데스크의 회귀 검사를 실행한다. 실제 PC 브라우저에서 취임 → 안내 → 업무 화면 이동과 글자 크기·가로 넘침을 확인한다. 이 작업은 초보 사용성 실험을 대체하지 않으므로 이해도·재미 개선을 수치로 단정하지 않는다.

다음 단계는 이 체계를 하단 분야 바와 대상별 행동 줄에 재사용하는 것이다. 하단 행동 바 자체는 이번 변경에 포함하지 않는다. 새 실행 버튼은 각 엔진의 권한·비용·승인 검증을 재사용한 뒤 연결한다.

### 로컬 검증 기록

- 관련 10개 테스트 파일의 213개 회귀 테스트 통과. 타입 검사 및 GitHub Pages용 빌드 통과. 기존 대형 번들 경고는 남아 있다.
- 1920×1080 및 2560×1440 PC 브라우저에서 안내 모달의 화면 내 배치와 가로 넘침 없음 확인.
- 기존 공통 CSS가 안내 문장을 10px로 축소하는 문제를 분리하고 본문·버튼의 실제 14px 표시 확인.
- 군사 경로는 편제·합동작전, 일반인 경로는 시민 활동실로 연결. 일반인의 국가 업무 10개는 잠김 상태 확인.
- Tab·Shift+Tab 순환, Esc 닫기, 원래 ‘할 수 있는 일’ 버튼으로 포커스 복귀 확인.
- 증거 화면: `play-guide-overview-1080p.png`, `play-guide-overview-1440p.png`, `play-guide-civilian-1080p.png`, `play-guide-confirm-1080p.png`.
- 확인 주소: `http://127.0.0.1:4197/`. 이번 변경은 로컬 작업이며 커밋·배포는 포함하지 않았다.
