# 해상 수송 관제판: 실제 작전과 현장 화면 연결

## 사용 흐름

`지휘 본부 → 현장 보기 → 해상 수송`에서 진행 중·확인 필요·확정 결과를 고른다. 배치도의 군수 창고/물류 조정실에서도 `병력 해상 수송 보기`로 이동한다. 전시와 국정 단계 모두 현재 소속의 실제 수송 기록을 사용한다.

1. 부대를 선택해 승선, 항해, 상륙 교전, 교두보 보급, 하선·재편을 확인한다.
2. 철회·구조·귀환은 별도 단계로 표시한다. 철회 요청만으로 귀환 완료가 되지 않는다.
3. `수송 지휘 화면 열기`로 정확히 그 작전의 기존 검토·승인 창구를 연다. 열람 권한에서는 보고·권한 확인으로 안내한다.
4. 현재 작전 구역, 귀환 목적지, 확정 도착지는 구분해 지도에 연결한다.
5. 종료 후 해당 수송의 확정 보고서를 직접 연다. 선택한 작전이 사라져도 다른 작전으로 자동 대체하지 않는다.

## 표현 원칙

- `seaTransportPresentation.ts`는 읽기 전용 모델이다. 시계, 임의 진행, 명령 실행, 자원 지급, 저장 정규화를 수행하지 않는다.
- 단계도는 주간 전략 시뮬레이션의 기록이다. 실시간 항법·정밀 선박 좌표를 뜻하지 않는다. 구조선 접근 위치와 아직 승선하지 않은 부대의 위치도 혼동하지 않도록 표시한다.
- 남은 횟수는 **현 단계의 조건부 최소 결산 횟수**다. 전체 작전의 도착 보장 시간이 아니다. 위험·권한 변경·구조 대기에서는 확정 예고를 하지 않는다.
- 부대 수송 종료와 호위 함대의 귀항·급유 종료는 별개다. 과거 참여 함대가 이미 다른 임무로 옮겼다면 현재 임무를 구분해 표시한다.
- 상륙 대상이 아군으로 바뀌면 실제 엔진의 하선 전환 절차를 반영한다. 하지 않은 상륙전을 완료했다고 표시하지 않는다.
- 확정 기록의 출발·목적지 지명은 저장된 당시 이름을 보존한다. 대체 도착지의 당시 이름이 저장돼 있지 않으면 현재 지명임을 명시한다.
- 다른 국가·미래 주차 기록을 현재 목록으로 섞지 않는다. 명시적으로 선택한 기록이 없어진 경우 다시 선택하도록 안내한다.

## 함께 수정한 연결 문제

- 기존 해상 수송 본부도 공유 모델의 국가·시간선 필터를 사용한다.
- 종료된 작전의 `operationId`와 일치하는 결과로만 연결한다.
- 다른 화면에서 작전을 열 때 미승인 계획 초안은 보존하되 기존 검토·승인 표시는 초기화한다.
- 한국 전시 캠페인의 기본 지도 초점이 사용자가 고른 수송 구역을 덮지 않도록, 지도 진입 후 명시적 위치를 적용한다.
- React 가이드에 따라 실제 진행 상태를 별도 UI 상태로 복제하지 않는다. 화면 상태는 필터·선택만 보유하며 현재 기록에서 표시를 계산한다.

## 검증 범위와 재현

자동 검증은 표시 모델, 관제판, 기존 수송 본부, 지휘부 연결, 해상 수송 엔진·통합, 함대 항법, 이전 지역 물류 화면을 대상으로 한다. 이전 수송의 자동 대체, 다른 국가 노출, 미래 기록, 철회 접수, 구조선과 부대의 구별, 함대 귀항, 아군 목적지 전환, 과거 지명 보존을 포함한다.

최종 관련 8개 테스트 파일의 341개 테스트가 모두 통과했다. 격리 검증 페이지도 별도로 TypeScript 검사에 통과했다. `git diff --check`에 오류가 없었다. 작업 중 초기 테스트 실행은 ESM 모듈을 spy하려는 테스트 구성 2건에서 실패했으며, 실제 UI 동작을 바꾸지 않고 테스트용 초기 상태 주입 방식을 수정한 뒤 최종 전체 실행으로 재검증했다.

격리된 로컬 검증 페이지: `http://127.0.0.1:4197/scripts/verify-sea-transport.html`

이 페이지는 실제 launch/advance/return/rescue 함수를 사용하지만 사용자의 저장을 읽거나 쓰지 않는다. `다음 결산`, `아군항 수송 초기화`, `상륙작전 초기화`, 권한 전환으로 재현할 수 있다. 게임의 배포 엔트리에서는 불러오지 않는다.

이번 실행에서 로컬 서버와 검증 페이지 소스 변환은 HTTP 200으로 확인했다. 브라우저 연결 도구는 두 차례 시간 초과로 실패했으므로 **이번 화면의 브라우저 조작·1080p/1440p/4K 시각 검증을 통과했다고 기록하지 않는다.** 이전 지역 물류 화면의 해상도 검증을 이번 해상 수송 화면의 결과로 재사용하지 않는다.

## 변경하지 않은 영역

해상 작전 엔진, 저장 스키마, 비용·손실 계산, 보직 권한, 명령 승인 조건은 변경하지 않았다. 새로운 실시간 함선 이동이나 해전 엔진을 구현한 묶음이 아니다. 기존 지역 물류 관제판 변경은 유지했다.

이번 묶음은 로컬 구현이다. 커밋·푸시·배포는 수행하지 않았다. 다음 후보는 참모별 지난주 실제 업무 결과를 인물 선택창과 연결하는 작업이다.
