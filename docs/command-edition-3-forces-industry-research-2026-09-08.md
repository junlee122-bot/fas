# Command Edition 3 — 합동군·산업·연구 작업대

2026-09-08. 이전 Command Edition 2의 다음 묶음 1번을 구현했다. 이번 범위는 군종별 전력 관리, 생산과 국정 산업, 국가 연구와 장비 개발국이다. 다른 국가·인물·사건을 대량 추가한 작업은 아니다.

## 바뀐 플레이 흐름

| 작업 | 진입 후 기본 구조 | 실제 집행과 확인 |
|---|---|---|
| 합동작전 | 전구 현황 / 작전 계획 / 진행·보고서 | 목표·전력·비용 검토 → 작전명령 승인 → 주간 진행 → 확정 보고서 |
| 해군·공군 | 전력 목록 + 선택 부대 하나의 상세 | 실제 척수·기체 수·준비도·배속 확인, 작전 중 정비 전환 차단 |
| 육군 | 사단 선택 / 부대 현황 / 지휘관·훈련 / 교리·전투 기록 | 실제 주둔지·장비·명령 표시, 지도·작전 현장으로 연결 |
| 산업 | 생산선 / 가동·예산 / 집하·수송 / 이행 약속 | 공장 ±1 초안 → 변경 승인, 물류는 예약·운송·실제 도착 분리 |
| 국가 연구 | 두 연구 슬롯 / 상태 필터·검색 / 한 과제 상세 | 시작과 일시 중지 명시, 선행·시대·슬롯 제한과 예상 기간 표시 |
| 장비 개발국 | 요약 / 장비 연구 / 시제 설계 / 배치·정비 | 연구·제작·채택 검토 → 기존 규칙으로 확정, 실제 진행은 별도 확인 |

전체 분야를 한 화면에 세로로 나열하지 않고 현재 작업에 필요한 상세만 연다. 하위 기능·사료·기존 엔진 규칙은 삭제하지 않았다. 모바일은 사단·생산선·함대·연구 대상 선택을 드롭다운으로 바꾸고 상세를 전폭으로 배치했다.

## 기능과 정확성

### 합동군

- 해군·공군은 실제 저장된 전력 수, 조직력, 경험, 정비·배속 상태를 표시한다.
- 작전 계획은 목표와 투입 군종의 적합성, 0대·정비 중·다른 작전 배속, 필요한 자원과 지휘 권한을 확인한다.
- 교리 선택은 미집행 검토다. 별도 적용 때 기존 비용 4 CP를 한 번 차감한다.
- 작전 승인은 진행·보고서 화면으로 연결된다. 예상 성공률과 확정 결과는 구분한다.
- 탐지하지 못한 적 작전 이름·개수는 노출하지 않는다. 불확실한 적 정보에 내부 실제 진척도를 사용하지 않는다.
- 육군 화면의 임의 고정값(차량 286/74, 주간 충원 +180 등)을 제거하고 실제 데이터가 있는 장비·주둔지·명령으로 대체했다.
- 훈련 설명에 기존 실제 비용 8 CP / 인력 12K를 표시했다. 인력이 부족하면 비활성화한다. 평시 공세는 기존 엔진 규칙에 맞춰 차단한다.

### 최고지도자 권한 충돌 수정

기존 `roleMandate`는 최고직의 직접 군사 권한을 인정했지만 `getRoleOperationalScope`는 비군인 검사를 먼저 수행했다. 실제 국가원수가 전부 정치 분류여서 군령권 예외에 도달하지 못했고, 직접 권한을 가진 채 상신을 요구받는 막다른 경로가 생겼다.

최고직(tier 1 또는 head-of-state) 예외를 먼저 적용했다. 일반 정치·정보 보직은 여전히 전황 열람만 가능하다. 실제 카탈로그의 13개국 최고직, 일반 정치·정보직 104개, 군사직 52개를 교차 검증했다. 보직 외 권한을 모든 사용자에게 풀어 준 변경이 아니다.

### 생산·산업·물류

- 공장 배정 초안은 선택만으로 실행되지 않는다. 승인 시 기존 `reallocateFactory`를 그대로 사용한다.
- 주차·국가·총 공장·생산선 배치가 변경되면 이전 초안은 만료된다. 진행 중·중복 승인을 방어한다.
- 전시 전망은 고정 1주차 계산이 아니라 App의 실제 다음 주·정책·조달 집중을 반영한 생산 전망을 사용한다.
- 국정 산업은 현재 승인 방침, 예상 생산 완료율, 병목, 지난 실제 결산을 분리한다. 예산은 한도 승인과 실제 현금 집행을 구분한다.
- 지역 물류는 국가 가용 비축 / 창고 / 예약 / 운송 / 도착을 혼동하지 않는다. 자동 예약은 기존 명시적 승인 방식이며 기본은 수동이다.
- 기존 이행 약속과 물류 엔진은 보존했다. 새 보상·감점·별도 재고를 만들지 않았다.

### 연구·장비

- 국가 연구의 슬롯 제한, 완료·시대·선행 조건과 예상 소요 주차를 표시한다. 진행률을 지우지 않고 일시 중지·재개한다.
- 연구 검색·필터에서 사라진 대상의 실행 버튼이 남던 문제를 막았다. 슬롯 카드를 누르면 해당 진행 과제로 필터·검색·선택이 함께 이동한다.
- 과거 과학자 소개는 1942년 출발 배경임을 명시한 접힌 참고 자료다. 현재 실제 배치 인물 또는 추가 보너스처럼 표현하지 않는다.
- 장비 연구 5 PP, 시제품 8 PP와 기존 견적, 제식 채택 6 PP와 기존 견적을 그대로 사용한다. 검토·명령 전달을 완성·성공으로 표시하지 않는다.
- 생산선의 ‘제식 장비 변경’과 빠른 이동의 ‘병기 준비도’는 장비 개발국 배치·정비 보기로 연결한다.

## 디자인과 구현

- Command Edition의 어두운 청회색 표면·따뜻한 강조색, 본문/조작/보조 정보 16/14/12px 기준을 적용했다.
- 한 대상 선택 → 상세 → 명시적 실행의 공통 구조를 사용했다.
- 군종 상단 메뉴의 오래된 sticky 동작을 제거해 스크롤 중 본문을 덮지 않게 했다.
- 실제 390px 검증에서 해군 상세가 한 글자씩 세로로 늘어지는 CSS 우선순위 충돌을 발견했다. 반응형 선언을 수정한 뒤 전폭 358px 단일 열을 재확인했다.
- React 품질 점검 스킬에 따라 원본에서 계산할 수 있는 선택 상세·전망을 중복 저장하지 않고, 렌더/열람과 실행 콜백을 분리했다.
- `ResearchDesk`, `ProductionDesk`, `LandForceRoster`를 App에서 분리했다. 큰 App 전체를 이번에 재작성한 것은 아니다.
- 저장 버전 38 유지. 기존 저장의 추가 마이그레이션은 필요 없다. 고해상도 지도 원본을 줄이거나 교체하지 않았다.

## 검증

- 최종 전체 테스트: 111개 파일, **1,017개 통과**. 운송 기록 이름과 마지막 문구 수정까지 반영한 전체 재실행 결과다.
- TypeScript, lint, 프로덕션 빌드, diff 검사 통과.
- 브라우저 오류 목록: 확인한 세션에서 0건.
- 데스크톱 1440×1000 / 모바일 390×844에서 새 작업대의 화면과 실제 조작을 점검했다. 국가 연구는 1280×900에서도 가로 넘침 없이 재확인했다.
- 모바일 합동군·육군·해군·생산·장비 배치/정비·확장된 조달 설명·물류·산업 결산 점검 구간에서 문서 가로 넘침 없음. 화면이 넘치지 않는다는 수치 검사와 실제 캡처 판독을 함께 했다.

| 실제 브라우저 조작 | 결과 |
|---|---|
| 연구 두 슬롯 사용 중 세 번째 과제 선택 | 선택으로 저장 변경 없음, 시작 차단 |
| 레이더 일시 중지 → 군수 교리 시작 | 레이더 68% 보존, 진행 슬롯 교체 |
| 완료 필터에서 이전 선택이 제외됨 | 이전 과제 실행 버튼 0개, 현재 목록에서 다시 선택 안내 |
| 공장 회수안 검토 → 승인 | 검토 시 불변, 승인 시 6→5개·효율 72→68, 주차 불변 |
| 장비 연구 검토 → 확정 | 정치력 120→115, 활성 프로젝트 생성·진척 0 |
| 전구사령관 호송작전 승인 | CP 42→35, 연료 74→65, 수송선 624→616, 진행 작전 1건 |
| 배속된 호송함대 선택 | 실제 작전 연결, 정비 전환 비활성 |
| 전시 실제 1주 진행 | 호송작전 20%·elapsedWeeks 1, 여전히 active; 장비 연구 14% |
| 최고 정치직으로 다시 진입 | 잘못된 군령권 상신 안내 제거 |
| 산업 방침·주간 한도 검토 | 승인 설정·현금 불변 |
| 생산 집중·추가 한도 5 승인 | 설정만 변경, 현금 920 유지; 실제 주간 결산에서 집행 |
| 공장 초안을 둔 채 국정 1주 진행 | 과거 배정 승인 비활성, 공장 수 5 유지 |
| 집하 노선 승인 뒤 국정 1주 진행 | 보병 장비 2,696개 창고 집하, 해당 물량을 가용 비축으로 이중 계산하지 않음 |
| 보병 장비 10개 예약 → 두 주 진행 | reserved → in-transit → delivered; 도착 영수증 10개, 도착 주차 3 |

브라우저 검증은 영국 캠페인과 별도 QA 상태를 사용했다. 전구사령관/최고 정치직 전환과 국정 단계는 저장 기반 테스트 fixture이며 자연 플레이로 해당 승진·종전을 달성한 증거가 아니다. 이번에 수백 회 또는 전 국가 장기 플레이테스트를 새로 수행하지 않았다. 사용자 로컬 저장은 검증 전 보관하고 종료 시 복원했으며, 키와 값의 완전 일치 및 QA 캠페인 제거를 확인했다.

## 다음 묶음

후속 진행: [Command Edition 4 — 외교·정보·보건 작업대](command-edition-4-diplomacy-intelligence-health-2026-09-08.md)에서 아래 1~3의 화면·실행 흐름을 개편했다. 동적 쌍방 협상이나 국가공작 주간 엔진까지 구현한 것은 아니며, 구체적인 완료 범위와 남은 항목은 후속 보고서에 분리했다.

1. **외교**: 국가·현안 선택 → 이해관계와 양측 제안 → 상신/협상/체결 → 관계·국경·교역의 실제 변화. 큰 카드 목록을 협상 작업대로 정리한다.
2. **정보**: 요원·공작·포섭 제안·이중스파이 관계를 선택 대상 중심으로 묶고, 내가 아는 정보와 실제 세계 상태를 구분한다.
3. **보건**: 위기 개요 → 대응 초안 → 비용·확인 시점 → 실제 주간 결과. 의료 정책 목록과 결과를 한 흐름으로 잇는다.
4. **깊은 레거시 보드**: 무기 수명주기·지휘관 성장·전투 교리 내부에는 아직 많은 카드와 작은 하위 설명이 남아 있다. 외부 작업대 전환이 내부 전면 재작성 완료를 뜻하지 않는다.
5. **구조적 부채**: 메인 JS 약 3.1MB(gzip 약 977KB), 공통 CSS 약 871KB. 큰 청크 경고는 남으며 후속 코드 분리가 필요하다. 지도 삽화 해상도 축소로 해결하지 않는다.
