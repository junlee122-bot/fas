# 헌정 창설·판사·검사 임명 시스템 조사 근거

## 구현 원칙

이 시스템은 특정 국가의 현행 헌법을 정답으로 강제하지 않는다. 사용자는 권력구조·기본권·사법심사·사법 인사·검찰 체계·비상권한·지방질서를 각각 선택한다. 서로 충돌하는 조항도 금지하지 않고, 낮은 신뢰·기관 충돌·권리구제 실패 같은 장기 비용으로 시뮬레이션한다.

실존 인물을 근거 없이 부패·편향 후보로 묘사하지 않기 위해 후보 시장의 법조인 이름은 명시적으로 가상 인물로 표시했다. 후보 성향과 검증 쟁점은 실제 제도에서 반복되는 임명·독립·책임성 문제를 합성했다.

## 공식 자료에서 반영한 요소

- 독일 기본법은 기본권, 연방·지방 권한, 의회가 선출하는 총리, 독립 연방헌법재판소, 구체적 위헌심사, 재판관 임기를 서로 다른 장으로 규정한다. 게임에서 헌법을 하나의 체제 버튼이 아니라 일곱 축으로 분리한 직접적인 구조적 근거다. 독일 연방법무부 공식 영문본: https://www.gesetze-im-internet.de/englisch_gg/englisch_gg.html
- 세계인권선언은 인간의 존엄, 표현·집회·종교, 공정재판뿐 아니라 노동·사회보장·교육을 함께 제시한다. 자유권 헌장과 사회권 헌장을 별도 선택지로 두되 혼합 가능한 것으로 설계했다. 유엔 공식 본문: https://www.un.org/en/about-us/universal-declaration-of-human-rights/
- OHCHR의 사법행정 매뉴얼은 검찰 기능이 재판 기능과 엄격히 분리되어야 하고, 판사·검사의 선발·승진·신분보장과 외부 압력 방지가 중요하다고 정리한다. 게임에서 법원 독립과 검찰 자율을 서로 다른 지표로 두고, 후보 검증과 임명 절차가 두 지표에 다르게 작용하도록 했다. 공식 PDF: https://www.ohchr.org/Documents/Publications/training9chapter4en.pdf
- 유럽평의회 베니스위원회 자료는 검찰총장의 제도적 독립, 개별 검사의 내부 독립, 검찰평의회·임명·교육·책임성을 구분한다. 독립 공소청, 법무장관 책임 검찰, 지역 분권 검찰, 통합 검찰감독원의 장단점 설계에 반영했다. 공식 자료: https://www.venice.coe.int/files/Publications/Reference_texts_judiciary_GBR_2016_A5_WEB.pdf

## 게임 내 결과 연결

- 헌법 조항: 법원 독립, 검찰 자율, 기본권 보호, 행정부 견제, 안정·정통성에 즉시 반영
- 비준 방식: 국민 지지와 정통성, 정치력·국고 비용을 변화
- 조항 충돌: 헌정 긴장으로 저장되어 이후 사건 확장에 사용할 수 있음
- 판사·검사 후보: 전문성·청렴·독립·연정 지지·보안 우려를 별도로 평가
- 인사 절차: 지명 → 2주 검증 → 1주 공개 청문 → 인준·재검증·철회·강행
- 임기: 보직별 3~12년 상당의 주 단위 임기 후 자동 공석 처리
