# Command Edition 2 — 사람·재정·국정 작업대

작성: 2026-09-08. 로컬 검증 주소: http://127.0.0.1:4197/

## 이번 묶음의 결과

이전 [공통 틀·지휘 데스크·납품 약속 구현](command-edition-design-and-delivery-2026-09-08.md)을 이어 조직 운영, 재정, 국가 운영 화면을 재구성했다. 콘텐츠를 제거하는 대신 현재 업무만 펼치고, 검토와 실제 집행을 구분한다. 저장 형식은 기존 버전 38을 유지한다. 이번 변경은 새 역사·전투 엔진을 추가한 것이 아니며, 기존 생산·수송·경제·국정 계산을 조작하기 쉽게 연결한 것이다.

## 1. 참모가 먼저 보이는 조직 운영

- 상위 작업대: 참모 스쿼드 / 후보 시장 / 면담·회의 / 국정 단계의 이행 약속.
- 스쿼드: 명단에서 실제 인물을 선택하면 능력·사기·충성·업무량·계약과 가능한 조치가 한 상세 영역에 나타난다.
- 보직 배치 / 책임 위임 / 분위기·계약은 별도 보기로 유지한다. 인사권·진단·기존 운용 정보는 필요할 때 펼친다.
- 후보 시장: 검색·분야·시장 범위·정렬을 먼저 제공하고, 선택한 후보의 조사 보고서에 조사·접촉·협상 조건을 모은다. 보고서 버튼의 접근성 이름에 실제 후보명을 포함한다.
- 선택은 보직 ID뿐 아니라 인물 ID를 보존한다. 열린 면담이 같은 보직의 후임에게 자동 연결되지 않으며, 권한 상실·상급기관 인물의 조작은 차단한다.
- 모바일: 가로로 밀어야 하는 참모 카드를 없애고 ‘참모 선택’ 드롭다운 바로 아래에 상세를 표시한다. 영어 부제·반복 설명을 줄이고 44px 조작 영역을 유지한다.

## 2. 사람에서 이행 근거로 이어지는 동선

- 국정 단계에서 관리 가능한 참모 상세 → 해당 인물의 이행 약속으로 이동한다.
- 약속 작성 / 실제 기록을 나눠 긴 입력 폼과 모든 기록이 동시에 쌓이지 않게 한다.
- 회의 화면은 동일한 저장 약속 중 가까운 검증부터 세 건을 보여준다. 별도의 약속 원장이나 보상을 만들지 않는다.
- 약속 기록 → 생산 배정 / 수송·도착으로 이동한다. 국가 가용 지표에서만 수송 링크를 제공하며 기존 산업 권한을 따른다.
- 담당자 선택의 직함도 스쿼드와 같은 전시·국정·국가 지위별 명칭을 사용한다.
- 진행량은 기존 실제 영수증에서 계산한다. 화면을 여는 행위, 전망값, 예약량은 생산·도착 실적으로 집계하지 않는다. 기한 전 목표량 도달도 기존 동일 인물·기한 검증을 건너뛰지 않는다.

## 3. 이해하고 확정하는 재정

- 재정 요약 / 재정 정책 / 기업 투자 / 외환·통화로 나눈다.
- 첫 화면은 현금, 경상수지, 차입 포함 증감, 월간 전망과 실제 세입·지출 구조를 보여준다. 국정 단계는 기존 국정 결산을 기준으로 한다.
- 기업·외화는 한 대상을 선택해 검토한다. 역사적 산업지분·국유기업 성과배분을 모두 현대의 상장주식인 것처럼 표현하지 않는다.
- 기업 매수·매도, 외화 매수·매도, 새 화폐 발행·역사 통화 복귀는 검토 → 명시적 확정 순서다.
- 전망은 기존 순수 계산 함수를 사용한다. 주차·잔고·외교관계·시장·통화 등 계산 조건이 바뀌면 이전 주문은 확정할 수 없고 최신 조건으로 재검토한다.
- 중복 확정은 한 번만 전달한다. 실행 콜백이 성공 여부를 반환하지 않는 기존 구조이므로 검토 UI 자체는 체결 성공을 단정하지 않고 실제 국고·기록 확인을 안내한다.
- 기존 세금·채권·가격 정책 선택은 여전히 즉시 정책 설정을 변경한다. 이번 확인 절차를 모든 정책에 적용했다고 주장하지 않는다.

## 4. 분야별 국정 데스크와 예산 검토

- 첫 화면: 이번 주 검토할 정책, 운영 참고선, 실제 국정 상태, 최근 기록.
- 정책·발전 / 재정·예산 / 헌정·사법 / 권력·노선 / 삶·언론 / 장기 계획으로 기존 기능을 분류한다.
- 국정 18개, 전시 9개 유효 세부 화면을 실제 렌더 테스트한다. 각 보드는 해당 보기를 열었을 때만 나타난다.
- 국가 성과 60·위임 50·불안 35·산업 65는 기존 UI 참고선이며, 네 항목 동시 달성만으로 승리나 보상이 확정되는 조건이 아님을 명시한다.
- 부처 배분의 ±5는 미집행 초안을 만든다. 다른 버튼을 누르면 초안을 교체하며 여러 폐쇄 상태 콜백을 한꺼번에 실행하지 않는다.
- 승인 전 국가·보직·주차·권한·진행 중 여부·기존 배분을 다시 확인한다. 기존 재배분 규칙으로 합계 100%를 유지하고 한 번만 적용한다.
- 초안 생성 시 검토 제목으로 초점·스크롤 이동, 폐기 시 원래 버튼, 승인 시 현재 배분 제목으로 돌아온다. 모션 감소 설정을 존중한다.
- 재정 정책 화면과 산업 전환의 예산 링크는 국정 개요가 아니라 예산 보기로 바로 연결한다.
- 조세 부담·총지출 ±5는 기존 즉시 설정 방식을 유지하고 이를 UI에 구분한다.

## 검증

- 전체 테스트: **108개 파일, 887개 통과**.
- TypeScript 및 프로덕션 빌드 통과.
- `git diff --check` 통과. CRLF 자동변환 안내와 큰 번들 경고는 오류와 구분한다.
- React 품질 점검에 따라 실제 게임 상태와 표시용 초안을 분리하고, 원본에서 계산 가능한 값을 별도 저장 상태로 복제하지 않았다.
- 브라우저: 1440×1000, 1280×900, 390×844. 조직·후보 보고서·예산·투자·외환·이행 기록의 점검 구간에서 문서 가로 넘침 없음.

| 실제 브라우저 흐름 | 확인한 결과 |
|---|---|
| 전시 영국 최고 정치 보직 → 기업 매수 검토 | 저장 국고 920 유지 |
| 해당 주문 확정 | 국고 895, 엔진 단위 25 한 번 차감 |
| 외화 매수 검토 → 확정 | 엔진 단위 10 차감, USD 39.696 편입, 거래 기록 1건 |
| 복지 5%p 증액안 검토 | 저장 배분 불변 |
| 재배분 승인 | 복지 15→20, 재건 25→20, 합계 100 |
| 초안을 두고 실제 국정 1주 진행 | 이전 예산 승인 비활성 |
| 금융 검토를 두고 실제 국정 1주 진행 | 이전 확정 비활성, 최신 조건 재검토 표시 |
| 참모 선택 → 약속 작성 → 회의 확인 | 같은 올리버 리틀턴 인물과 약속 연결 |
| 실제 두 주 진행 후 이행 기록 | 국가 가용 실적 42, 실제 영수증 2건; 기한 전이라 최종 성공 단정 없음 |
| 약속의 수송·도착 확인 | 실제 지역 물류 작업대 이동, 이동만으로 운송 지시 없음 |
| 재무성 국가 운영 예산 링크 | `data-nation-view=budget` 직접 진입 |
| 모바일 예산 초안 생성·폐기 | 검토 제목 초점 → 원래 교육·과학 버튼 초점 복귀 |
| 모바일 참모 선택 목록 변경 | 동일 인물 상세와 이행 약속 연결, 가로 명단 스크롤 제거 |

브라우저 검증은 영국 캠페인과 별도의 국정 단계 QA 상태를 사용했다. 국정 QA는 저장 데이터를 단계 전환한 테스트용 fixture이며, 자연 플레이로 1942년에 종전을 달성했다는 증거가 아니다. 수백 회·전 국가 장기 플레이를 이번 변경에서 새로 수행한 것은 아니다. 검증 전 사용자 로컬 저장을 보관하고 검증 후 복원했다.

개발 도중 TSX를 먼저 쓰고 새 CSS가 아직 생성되지 않은 짧은 구간에서 OrganizationPanel 동적 import 오류 2건이 기록됐다. CSS 작성 후 최종 새로고침과 화면 재진입은 정상이며, 기존 오류 기록과 최종 재현 여부를 구분했다.

## 다음 묶음의 경계

후속 1번은 [Command Edition 3 — 합동군·산업·연구](command-edition-3-forces-industry-research-2026-09-08.md)에서 구현·검증했다. 아래 2~4번의 잔여 범위는 후속 보고서에 이어 기록한다.

1. 합동군·산업·연구의 현장 화면도 동일한 정보 계층으로 통합한다. 선택한 부대/생산선의 현재 상태 → 명령 → 진행 → 실제 결과가 한 위치에서 이어지게 한다.
2. 외교·정보·보건은 큰 카드 목록에서 상대/작전/위기 선택 + 상세 검토 구조로 옮긴다. 상신·직접 결재·열람 경계는 유지한다.
3. 기존 세부 보드의 작은 글자·과도한 설명과 App의 페이지별 결합을 단계적으로 정리한다. 현재 새 껍질 내부의 일부 레거시 보드는 아직 전면 재작성하지 않았다.
4. 큰 JS/CSS 청크는 남아 있다. 최종 주 청크는 약 3.09MB JS, 공통 CSS 약 850KB이며 후속 코드 분리가 필요하다. 고해상도 지도 원본은 줄이거나 교체하지 않았다.

이번 턴에는 커밋·원격 배포를 실행하지 않았다.
