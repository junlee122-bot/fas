# Higgsfield 다중 화면 적용 — 2026-09-18

## 결과

Higgsfield MCP로 새 삽화 6장을 생성하고 기존 게임 UI의 세 영역에 적용했다.
색상 체계·탐색·게임 엔진·저장·권한·결재 판정·지도 좌표를 변경하지 않았다.
영상이나 역사 인물 초상, 실제 사건 사진을 생성했다는 의미가 아니다.

## 적용 위치

| 영역 | 적용 내용 | 선택 기준 |
|---|---|---|
| 세계 주보 | 인쇄·라디오·TV·디지털 편집국 4종 | 선택한 보관 호의 `issue.media.id` |
| 주간 브리핑 | 같은 보도 환경의 작은 보조 삽화 | 기본 닫힌 ‘보도 매체 소개’ |
| 지휘 본부 → 현장 보기 | 민수 작업장·보건 준비 정물 | 산업 또는 보건 거점 선택 |
| 도전과제 | 평화의 배당·다음 위기 이전에·유행을 꺾은 주 | 기존 업적 조건과 저장된 해금 기록 |

7개 매체 시대는 4개 그림으로 묶었다. TV/위성은 방송 도구를, 웹/라이브/시민 네트워크는 디지털 검증 환경을 공유한다.
2035년 이후 시민 네트워크에는 ‘미래 매체의 상징적 표현’ 문구를 표시한다.
이는 각 연도의 편집국을 완벽하게 재현한 사료가 아니다. 알 수 없는 매체에는 그림을 표시하지 않는다.
1936–1959년으로 제한된 기존 지휘 데스크 삽화의 연도 범위는 그대로 유지했다.

현장 그림은 자원이나 건물 상태를 나타내지 않는다. 공급 수치로 도시 피해·복구를 추론하지 않는다.
아직 달성하지 않은 업적에는 ‘목표를 상징한 삽화’를, 실제 해금 기록이 있을 때만 ‘성과를 상징한 삽화’를 표시한다.
그림을 열거나 읽는 행위가 새로운 보상·결재·성과 판정을 발생시키지 않는다.

## 생성과 품질

- 공급자: Higgsfield MCP, 모델 GPT Image 2.5, flare / high / 2k.
- 비용: 244 → 226, 실제 18크레딧. 무료 영상 생성권은 사용하지 않았다.
- 편집국 4장: 각 2688×1520. 산업·보건 2장: 각 2048×1360.
- PNG 원본을 로컬 보관하고 무손실 WebP로 변환했다. 6장 모두 디코딩한 RGBA 픽셀이 원본과 완전히 일치한다.
- 리사이즈·업스케일·파일당 3MB 제한·손실 압축을 적용하지 않았다.
- 여섯 원본을 직접 시각 검토했다. 새 에셋은 같은 절제된 유화·과슈 방향을 유지한다.
- 4번 요청은 제출 단계 429로 거절되어 그 요청만 한 번 재제출했다. 나머지 성공 요청은 중복 생성하지 않았다.
- 출처 설명·버튼·수치는 이미지가 아닌 실제 HTML이다.
- React 지침에 따라 파생 상태나 effect를 추가하지 않고 순수 매체 lookup을 사용했다. 목록·보조 그림은 lazy/async 로딩, 업적 해금 팝업은 즉시 표시를 유지한다.

정확한 프롬프트는 [생성 계획](../design/higgsfield-multi-surface-production.json),
작업 ID·크기·파일 해시는 [생성 기록](../design/higgsfield-multi-surface-generation.json)에 있다.
생성물이라는 사실을 표시하는 것은 별도의 법률상 권리 검토를 완료했다는 뜻은 아니다.

## 검증

- 관련 Vitest: **14개 파일, 211개 테스트 통과**.
- 최종 `npm run build`: TypeScript와 Vite 빌드 통과, 2057개 모듈.
- `git diff --check`: 통과.
- 기존 큰 JavaScript 청크 경고는 남아 있다. 이번 작업에서 전체 번들 성능 문제를 해결했다고 주장하지 않는다.
- 전용 agent-browser 세션에서 새 영국 캠페인을 열어 확인했다. 사용자의 기존 브라우저 저장 파일은 건드리지 않았다.
- 1080p: 산업 현장, 열린 브리핑 삽화, 세계 주보, 미해금 보건 도전과제.
- 1440p: 보건 현장, 브리핑 삽화 기본 접힘 및 펼치기.
- 4K: 세계 주보의 제한된 읽기 폭, 그림 로딩, 매체 소개 영역 넘침.
- 검사한 화면에서 가로 페이지 넘침·개발 오류 오버레이 없음. 수집된 브라우저 오류 없음.
- 1080p 주보 그림 실제 표시 240×약137px, 펼친 브리핑 176×약100px.
- 산업·보건 그림은 112×약74px로 본문 조작부를 가리지 않는다.
- 7개 시대 매핑·보관 호 유지·미래 고지는 컴포넌트 테스트로 확인했다. 실제 캠페인을 2060년까지 진행한 장기 검증은 이번 범위가 아니다.
- 도전과제 잠금 화면을 브라우저로, 저장된 해금 유무·실제 조건 경계·무부작용은 테스트로 확인했다. 검증을 위해 새 업적을 강제로 지급하지 않았다.

## 실행·배포 범위

로컬 확인 주소는 http://127.0.0.1:4197/ 이다. 프시케의 4173 포트는 건드리지 않았다.
이번 변경은 로컬 반영·빌드·화면 검증까지 완료했다. 이번 차례에 새 커밋이나 원격 배포는 하지 않았다.
기존 README 변경·다른 원자료·이전 캡처 파일은 유지했다.

후속 후보는 전후 회의실, 현대 상황실, 실제 도시 피해 데이터와 연결되는 복구 장면, 선택적으로 재생하는 짧은 서사 영상이다.
이번에는 이들을 구현·생성하지 않았으며 추가 생성 비용도 사용하지 않았다.
