# 전후 군수 운영 개선 및 후속 액티브 월드 설계

작성: 2026-09-08. 요청: 다음 구현 묶음과 후속 설계를 병행한다.

## 1. 이번에 실제 바뀐 플레이

전쟁에서 국가 운영으로 전환한 뒤에도 **공장 배치 → 가동 방침 → 예산·원료 확인 → 다음 주 납품 → 비축·결산**이 이어진다. 전후에 남아 있던 생산 배치, 선지급 장비 연구, 병기 작업지시가 멈추던 경로를 연결했다.

- 산업 전환에 `국정 군수 납품 지휘실` 추가. 균형 가동·생산 집중·설비 보존을 비교하고 결재한다.
- 선택만 한 방침과 승인된 방침을 분리한다. 미결재 미리보기·취소·화면 열람으로는 비용이나 비축이 바뀌지 않는다.
- 보병 장비·전차·항공기·함선/수송선·야포·차량 각각의 생산 계획과 실제 가능한 다음 주 입고를 구분한다.
- 예산·연료·강철 부족과 공장 초과 배치가 납품을 제한한다. 없는 원료로 무료 생산하지 않는다.
- 승인된 추가 현금 한도는 주간 상한이지 정액 청구가 아니다. 실제 사용분만 차감한다.
- 원료는 명시적 1회 구매로 확보한다. 자동 구매·자동 군수 차입은 추가하지 않았다.
- 국정 장비 연구와 선지급 정비 작업을 주간 처리한다. 완료 효과와 작업비를 다시 적용하지 않는다. 기간 위임 중 완료가 발생하면 해당 검증 지점에서 멈춘다.
- 본부의 현장 생산 조정, 산업 납품 전망, 국정 재무성은 같은 예측/결산 계산을 사용한다.
- 국정 재무성의 전시 세금·전쟁채권·가격통제 버튼을 국정 예산 안내로 대체한다. 주식·외환 매수/매각은 유지하며 국정 자동입금과 미연결인 배당 전망은 참고값으로 명시한다.
- 국정 강철에 실제로 발생하지 않던 `+9/주` 표시를 제거하고, 국정 일반 연구의 주간 증가량 표시를 실제 계산에 맞췄다.

## 2. 비용과 권한의 경계

기본 국정 공공지출에는 안보예산이 이미 포함되어 있다. 현재 게임 규칙은 그 예산의 50%를 군수 집행 한도로 간주하며 **이 금액을 국고에서 두 번 빼지 않는다**. 부족분 중 사용자가 허용한 추가 현금의 실제 집행분만 지출·수지·국고에 한 번 합친다.

추가 한도는 회계 기준 단위 0/2/5/10M에서 고르고 화면에는 국가 화폐로 환산한다. 재정·보건 지출뿐 아니라 같은 주 먼저 집행되는 국가 프로그램 비용까지 현금을 예약한다. 예상 수입이 있어도 기존 현금보다 큰 선지출 한도를 만들지 않는다. 기존 국가 예산 자체의 차입 규칙은 그대로이며, 군수 부족분을 이유로 새 자동 차입을 만들지는 않는다.

산업 직접권한이 있는 군사 보직은 기존 예산 안에서 가동 방침과 공장 배치를 조절한다. **추가 한도 변경과 원료 구매에는 재정 또는 국정 직접권한도 필요하다.** 이미 승인된 상시 한도는 권한 상실만으로 자동 철회하지 않으며, 국가 이동·새 캠페인·국정 전환 시 기본값으로 초기화한다.

수량별 제조비·가동 정책 배수·원료 구매가는 게임 내 추상 균형 규칙이다. 실제 역사적 생산 원가, 실물 톤수, 무역시장 가격 또는 지역 수송망을 완벽하게 재현했다는 뜻이 아니다. 설비 보존 정책은 공장 운용 방식이지 병기 준비도를 직접 올리는 정비 버튼이 아니다.

과거 영수증의 화폐 표시는 현재 화폐 환산을 사용하므로 환율/물가가 바뀌면 표시액이 달라질 수 있다. 회계 원본과 예상/실제 장비 수량 비교는 별도로 보존한다. 시점별 환율을 영수증에 고정하는 확장은 후속 과제로 남긴다.

## 3. 구현과 저장

| --- | --- | --- |
| 주간 생산 | `src/postwarIndustry.ts` | 순수 전망, 가동/자원/예산 제한, 정수 납품, 국가·주차 중복 방지 |

| 조작 화면 | `src/PostwarIndustryBoard.tsx` / `.css` | 미결재 미리보기, 승인, 권한 제한, 납품 전망·영수증 |
| 기존 화면 | `src/App.tsx`, `src/LivingWorldScene.tsx`, `src/EconomicMinistry.tsx` | 실제 주간 실행과 공통 전망·장부 연결 |

상위 저장 버전을 36으로 올렸다. 신규 생성, 저장/불러오기, 전후 전환, 국가 이적, 초기화를 연결했다. 오래된 저장에서 누락된 과거 수십 년의 군수 물량을 소급 지급하지 않는다. 연구/정비 역시 오래 멈춰 있었다는 이유로 한 번에 수십 년 분량을 처리하지 않는다.

결산 병합은 국가·주차를 검사하고 동일 보고서에 이미 군수 집행 표식이 있으면 재병합하지 않는다. 실제 App 경로는 병합된 자원 델타와 별도 비축 델타를 각각 한 번씩만 적용한다.

## 5. 동시에 구체화한 후속 설계

[후속 구현 계약](active-world-next-slices-2026-09-08.md)은 이전 공식자료 조사에서 확인한 FM·CK3·HOI4·Total War·Stellaris 등의 원리를 우리 원본 상태·권한·결산에 맞춰 적용한다. 다른 게임의 코드·미술·대사를 복제하지 않는다.

1. **작전 현장:** 공세별 불변 ID → 같은 지도/부대/전투 결산 추적 → 다음 교전 전 중단 요청. 실제 지원과 손실이 보이는 한 작전을 먼저 끝까지 연결한다.
2. **인물 회의장:** 실제 참모와 사건 근거 → 권한 안에서 중재 → 기존 검증 주차 → 관계·책임의 후속 확인. 회의용 별도 호감도나 중복 비용을 만들지 않는다.
3. **지역 생산·수송:** 국가 생산 역량의 지역 귀속과 미위치 계정을 구분 → 두 창고·한 노선부터 예약/운송/도착 구현 → 국가 총비축 보존. 도시/철도 위치를 사료 없이 임의 생성하지 않는다.

각 묶음에 데이터 타입, 원본 소유자, 상태 전환, 구세이브 처리, 실패 조건, 첫 플레이 흐름, 필수 테스트를 작성했다. 전쟁 지휘관·망명정부 정치가·비밀/저항 활동가·식민지 민간인은 같은 만능 콘솔이 아닌 권한별 작업대로 설계한다.

## 6. 아직 구현했다고 말할 수 없는 것

- 지역별 실물 창고와 수송 경로는 설계 단계다. 이번 원료 구매는 즉시 구매이고, 공장 화면은 국가 집계다.
- 국정에서 새 함대/공군 합동 임무를 자유롭게 시작하거나, 전시의 진행 중 합동 임무를 평시 엔진으로 완전 이관하는 작업은 남아 있다.
- 국정 주식 배당의 자동 입금은 미연결이다. 이번에는 오인 표시와 잘못된 재정 패널부터 바로잡았다.
- 안보예산의 내부 몫과 원료 가격은 균형 조정이 필요하다. 612개 회귀 통과를 장기 재미·경제 균형 입증으로 과장하지 않는다.
- 작전 현장·회의장·지역 수송의 신규 행동은 위 후속 설계이며, 이번 납품 기능과 함께 모두 구현됐다는 뜻이 아니다.
