1. 전시 검열령 → 허가 언론제 → 다원 언론법 → 헌법상 언론자유의 4단계 언론법
2. 시대별 신문 서면 문답, 라디오 대담, TV 인터뷰, 위성 생중계, 온라인 문답, 라이브 스트림, 시민 검증망
3. 언론 측 인터뷰 요청과 사용자의 능동적 인터뷰 제안
4. 현재 경제·선거·안보·외교·개인생활 상태에서 자동 생성되는 질문
5. 솔직한 답변, 원칙 중심 답변, 사실검증, 답변 유보, 인터뷰 거절과 각각의 예상 결과
6. 보직 단계, 군사·정치·정보 소속 집단, 선거, 사회 불안, 가족법, 공개 경계에서 계산되는 폭로 위험
7. 유력 경쟁자·당내 경쟁파·장성·정보기관 감찰파가 편집국에 제보하는 동기 모델
8. 제보·소문 → 취재·교차검증 → 보도 → 대응·해결의 다주차 사건 흐름
9. 자기 언어로 공개, 사생활 원칙 선언, 독립 검증, 법적 보호, 제보자 공격의 대응 선택
10. 언론 신뢰·접근·적대, 정통성·불안·안정도·국민 신뢰와 배우자 관계의 후속 변화
11. 1942년 전쟁 단계부터 전시 언론 데스크가 작동하고, 종전·건국 전환 뒤에도 같은 개인 정보·인터뷰·폭로 기록이 유지

## 설계 원칙

폭로 위험 화면은 모든 가산 요인을 숫자와 설명으로 공개한다. 정체성 자체는 능력·충성·정통성 페널티가 아니다. 혼인평등·사생활 보호·독립 사법·언론중재가 갖춰진 가능세계에서는 같은 공개가 정치 공격으로 작동하기 어렵다.

자유언론은 폭로 가능성을 완전히 없애는 장치가 아니다. 대신 보도 전 검증, 반론권, 취재원 보호와 사생활 구제 절차를 강화한다. 통제 언론에서는 공개 기사는 줄 수 있지만 정보기관·집권파의 협박과 선택적 유출 위험이 남는다.

## 검증 항목

- 최고위 보직·선거 경쟁·높은 불안·제한적 가족법에서 폭로 위험 증가
- 사생활 보호와 혼인평등 아래에서 공개 후 정치적 피해 감소
- 비공개·이성애 프로필에 확인되지 않은 성적 지향 폭로를 생성하지 않음
- 인터뷰 요청 → 답변 → 신뢰·접근·적대 변화 저장
- 소문 → 검증 → 보도 흐름이 여러 주에 걸쳐 진행
- 오래된 저장 데이터에 언론 상태가 없어도 국가별 초기 언론법으로 복구
